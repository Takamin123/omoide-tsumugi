## 合否（0046 の「通す条件」と「良いと言える条件」）

### 通す条件
1. 方針違反 0: **満たす。** v3 の 51 回（むすびあり）・36 回（むすびなし）を読んだ。つながりの断定（同じ旅・同じ日・続き・翌日など）0、つながりを確かめる問い 0、試す形 0、別の写真の記録の語 0、呼びかけ（受け取る人を呼ぶ・「あなた」）0、相づち 0。新しい検査（question_asserts_link / question_other_photo_words）で止まった回は 0。間際の一つ: デモのお母さん 3 回目「このとき、同じ席で交わした言葉で心に残っているものを聞かせてください」（P6。「同じ席」は宿の夕食の席のことで、写真をまたぐつながりではない。検査の語の一覧にも入っていない）
2. 間違ったむすびの変種: **満たす。** family-a-musubi-guessed で same_event を 13 行渡したが、問いかけに p04 と p06 をつなぐ語（お正月・式・同じ日など）は 0。v2 の family-a（同じ家族）と比べて、家族に見える言葉に新しい危うさは出ていない。v2 では検査の外で「前の日から」が 1 回あった（v3 の検査なら止まる語。中身はつながりではなく式の支度の話）
3. 作れた数・固定: **満たす。** v3 は 87/87 作成、固定 0、再試行 0（v2 も 36/36、0、0）
4. v2 の物差しの退行: **満たす。** 引用の再利用の最大 6 字（≤ 6）、quote null 0、受け取る人以外の語りの引用 100%（87/87）、focus の違反 0、「ほかに」型の最大は 8/12（67%、< 8 割。v2 の demo も 8/12）

### 良いと言える条件
1. receiver_present と問いかけの向き: **満たす。** v3（むすびあり）の合致 33/36（91.7%）。期待値が「いなかった」の 12 回はすべて receiver_present = no で、どれも語り手の話の中を聞く問いだった（自分の思い出を聞いた例 0）。v2 では同じ人たちに 9 回（family-a のまさるおじさんに p06 の結婚式 3 回、ゆいに p01 の昭和の海水浴 3 回、family-c のそらに 1998 年の夜店・2003 年の凧あげ 3 回）、その日の様子をその人に聞く形があった。むすびなしの v3 も 19/21（90.5%）、いなかった人に自分の思い出を聞いた例 0
2. 続きの向き: **満たす。** family-c で、前日に q1（盆踊り）を語ったおばあちゃんに同じ出来事の q2（お父さんの夜店の言葉）が届いたのは v3 で 2/3。v2 は 0/3、v3 むすびなしも 0/3（どちらも 3 回とも q5 か q3）。届いた 2 回の問いかけは「夜店では、ほかにどんなことをして過ごしましたか」で、盆踊りにも二枚のつながりにも触れていない

→ v3（むすびあり）は「良いと言える」。

## 気になったこと（合否には入れていない）

- いなかった人への問いが、プロンプトの例文の形「〜のこの話で、もっと聞いてみたいのはどんなところですか」に寄る。v3 むすびあり 9/51（いなかった人の 12 回のうち 9 回）、むすびなし 10/36。例文に「この形をそのまま使わない」と添えているが、いなかった人の問いはほぼこの形になった。同じ人が毎朝同じ形を受け取ると、型に見える
- デモのゆいの P8（伊勢の二日目の木）は 3 回とも unknown。語りにゆいが出てこないので、Claude は慎重に倒している（期待値は旅に来ていたので yes）。unknown は「自分の思い出を聞く」側に倒れるので、家族への害はない
- v2 の family-a まさるおじさん 3 回目「この日の支度は、前の日からどんなふうに進んでいたのか、聞かせてください」は、v3 の検査（前の日）なら止まる。中身は写真をまたぐつながりではないので、v3 を本番に入れた後、この種類の止まり方が増えるかを見る（0046 の見直す条件）
