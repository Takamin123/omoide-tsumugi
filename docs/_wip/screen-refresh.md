# 画面の見直し（2026-11-05）の詳細設計（作業中。終わったら消す）

- 定数: styles.css の :root は家族の画面、.elder（.home-shell.elder と祖父母の拡大の画面）は祖父母の最低ライン。同じ名前を .elder で替える
- 家族の言葉の箱 .paper（EntranceView の quote、Narrations の語りの中身）。紙の色はここだけ
- カード .card-soft: 入り口の写真＋言葉、問いかけ＋答えるボタン、返事のタブの写真ごとの節、アルバムの写真ごとの語り
- ボタン: 声で話す/話す=青で塗る、文字で書く/書く=青い枠。聞く・読み上げ=淡い青の丸、丸い再生印。押したら scale(.97) 0.1s（reduced-motion では付けない）
- タブ: 印（aria-hidden）＋語、今のタブは太字と印の後ろの淡い青
- アルバム: 白い縁に影と -0.6deg、前後の写真を両端に薄く（帯の slide の幅を狭め、隣を見せる）、丸い矢印、何枚目かの下に点（13 枚以上・狭い幅では出さない）、語りは一枚のカード、返事は一段下げる、追加は点線
- 返事のタブ: 開いた時点で未読だった語りに淡い青の地と枠と札「新しい」（そのタブを開いている間だけ）
