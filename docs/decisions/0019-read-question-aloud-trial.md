# 0019 問いかけを OpenAI の読み上げで試す（0015 の一部を置き換え）

- 日付: 2026-11-03
- 状態: 採用（試しの段階。採るかは実機で聞いてから人間が決める）
- 決めた人: 人間（読み上げること、OpenAI を試すこと、明示の文）。進め方は fable-advisor に相談（メインの会話）

## 決めたこと
- **Claude の問いかけだけ** を、OpenAI の読み上げで読む。文字起こしと添える家族の言葉は読まない（0015 のまま）。speechSynthesis は使わない（0015 のまま）
- まず開発用の `/check`（0014）に読み上げの確かめを足す。iPhone、iPad、Android で聞き比べ、採るかどうかを人間が決める。聞く観点は、速さ、落ち着き（相づちや感情が乗っていないか）、日本語の自然さ、三台の間の差
- 採るときの形:
  - 毎朝の処理で、問いかけの検査を通った後に音声を作り、R2 に保存する（PhotoStore を通す）。画面を開いたときには作らない。作るのが失敗しても入り口は出し、家族には知らせない。同じ日に二度は作らない。対象は kind=claude の入り口だけ
  - 声への指示: ゆっくり、落ち着いて、感情を足さない。問いかけの文だけを読み、前置きや相づちを足さない
  - 祖父母の画面: **自動では流さない。押して聞く。** 問いかけのすぐ下に、補助の大きさのボタン（48px 以上で、主な動作のマイクより小さい）を置く
  - 明示の文: ボタンのすぐそばに、いつも **「AI の声で読みます」** と出す（16px 以上）
  - 差し替えられる層（ports）を通し、モデルの終了に合わせて外せる形にする
- 0015 のうち「問いかけは読み上げない」と「OpenAI の読み上げも使わない」をこの判断で置き換える。ほかの部分は残る

## 理由
- 人間の判断: 祖父母に問いかけを声でも届けたい。ブラウザの読み上げは実機で機械的に聞こえた（0015 の根拠）ので、OpenAI を試す
- OpenAI の利用方針は、AI の声であることを利用者に明示するよう求めている。人間は、義務の文言にいちばん近い「AI の声で読みます」を選んだ。「AI を前に出さない」という方針（implementation-policy「家族に見せる言葉」）の例外として、この一文だけを許す
- 「AI は話し相手にならない」との緊張は残る。そのため自動では流さず、祖父母が押したときだけ読む。主な動作はマイク一つのままにする
- 画面を開いている最中に外のモデルを呼ばない（implementation-policy 2）

## 退けた案とその理由
- 開いたときに音声を作る: 方針に反する。遅く、同じ結果にならない
- 自動で流す: AI が先に話しかける形になる。ブラウザも、操作なしの再生は止める
- 明示の文を「機械の声で読みます」にする（fable-advisor の推し）: 人間が、義務の文言に近い方を選んだ
- 家族の言葉も読む: 本人と祖父母の間に機械の声が挟まる（0015）
- speechSynthesis に戻す: 実機の三台とも違和感があった（0015）
