### 言葉と流れ（fable-advisor に相談）
- 答え方: 祖父母は [はなす][かく]。同じ重さ（白い枠。0034 と同じ）。「はなす」は押した瞬間に録音が始まり「おわる」で送る（0008 の二度押しのまま。家族の「声で話す」→「話す」より一手少ない）。流れの違いはこれ一つだけ。「かく」で文字の欄（読み上げの名前「かく」）と [やめる][おくる]。青は「おわる」「おくる」に残す
- 送れなかった: 声も文字も「おくれませんでした。「おくる」を おすと、もういちど おくります」と [やめる][おくる]。文字は欄を開いたまま、同じ文なら同じ requestId で送り直す。「やめる」は捨てて閉じる（確認なし）

- 語りの欄（祖父母）: 「へんじ」。声は「こえを きく」と、そばに入り口と同じ注「{呼ばれ方}の声（13秒）」。流している間「とめる」。言葉の糸、タブ「今日」「アルバム」、「4枚のうち 1枚」「2枚目」、矢印の読み上げの名前は家族と同じ。拡大の「とじる」は 0040 のまま

- 読み込めなかった: 祖父母の画面では、今日の入り口とアルバムの一覧の両方で `words.elder.errors`（「ひらけませんでした。「もういちど」を おしてください」と「もういちど」／「かぞくに しらせてください」）。入り口が開けていて一覧だけ読めなかったときは、今日のタブには出さず、アルバムで出す
- 置き換え: 0008「祖父母の画面に文字起こしは出さない」（祖父母にもアルバムの語りが出る）、0028「「はなす」は横いっぱいの高いボタン」（二つのボタンが一段を分ける。高さは下げない）、0034「祖父母の画面は変えない」

## 理由

- 人間の決定。部品を共有すれば、家族の画面の直し（0034・0035・0040・0041）が祖父母の画面にもそのまま届き、二つの画面が食い違わない
- 0008「祖父母のボタンは一語のひらがな」。これまでの語はすべて動詞で、「かく」はその列に並ぶ
- 0008 が三つ目の動作を退けた理由「話す前に構えさせる」。親の試しの途中で「はなす」の押し方を増やさない
- requirements の書き換え（声か文字で）。0034 が家族で両方白にした理由がそのまま当たる
- 「おくりました」を残すのは 0028「目を離していると見逃す」。一つだけにするのは、何か所にも残ると今のものが分からないため
- 返事の欄の上の名前の行は、語りの話者名と見分けがつかない。端末は一人に結びつく（0036・0037）
- 写真が開いているそばに「ひらけませんでした」は食い違う
- 帯の上の余白は飾りの間で、写真や文字の大きさ（方針の数値）ではない。らくらくスマホ（高さ 640px 前後・大きい文字）で語り一つが見えることを取る
- 語りの中の間（話者名・本文・「へんじ」の間）を詰めたのも同じ理由。足りなかったのは 640px で 8px・667px で 5px で、ここを 0.25rem 詰めれば 12px 浮き、文字・行間・ボタン・写真のどれにも触れずに済む。祖父母の画面だけなのは、家族の画面は今の間で入っている（悪くしないため触らない）から

## 退けた案とその理由

- [こえで][もじで] → 選んでから「はなす」: 一手増える。語が動詞でない
- 家族と同じ「声で話す」「文字で書く」: 0008 から外れる
- 「はなす」だけ青: 青（送る・録る）の意味が「録り始める」まで広がる。requirements の書き換えと合わない
- 返事の「おくりました」を家族と同じ 4 秒: 0028 の理由が返事でも効く
- 声の注を「13秒」だけ・「声（13秒）」: 数字が裸／語として立たない。同じものには同じ形を一つ
- 言葉の糸の「言葉」をひらがなに: 同じ文を二通りにしない
- 返事の欄にも呼ばれ方: その人の語りに見える
- アルバムの上に呼ばれ方の行: 0034・0041 の高さの条件を食う
- 二つのボタンを幅で縦に積む（前の祖父母の画面の auto-fit）: 360px・100% でも縦に積まれ、段が 235px になった
- 640px で帯の写真の下限を下げる: 0041 で退けた（写真が見出しの小さい写真とほぼ同じ大きさになる）
- 祖父母のアルバムの語りの文字を家族の大きさにする: 祖父母に残すと決めた大きさを下げる
- 語りの本文の行間を 1.8 から下げる（1.5 以上は守れる）: 語った言葉そのものの読みやすさを削る。間を詰めれば足りる
- 「へんじ」を話者名の横に置く: 一つの語りの読む順（だれが・何を・返事）が変わり、話者名の行が「へんじ」の高さ（78px）まで高くなる。画面の流れの変更になる
- 見出しを低くする: 見出しは家族の画面と共有で、0041 で 68px に決めている。小さい写真（48px）が下限になる
- Elder.tsx に家族の画面の部品を写して持つ: 二重に持つと直しが片方に届かない（人間）

## 見直す条件

- 親が「かく」を押さない・戸惑う → 語を替える（長くしない）。どちらを押すか迷って答えなくなった → 「はなす」を青にする（「かく」は消さない）
- 親が自分の声の文字起こし（聞き違い）を嫌がった → 祖父母の画面で自分の声の語りを再生だけにするかを人間に戻す
- 別の人のリンクを開く取り違えが起きた → アルバムの上にも呼ばれ方を置く
- 声の注が幅に入らないのが気になると言われた → 名前を落として「声（13秒）」
- 家族の画面でも「声で話す」の一手が重いと分かった → 家族も押した瞬間に録音を始める形にそろえるかを人間に聞く
- 人間が「はなす」のすぐ録音を採らないと決めた → 選んでから「はなす」の形に替える
- 高さ 640px 前後で文字 150% の家族の画面の人がいたとき → 帯の上の余白を詰めることを家族の画面にも広げる（2026-11-04 に広げた。0041 の追記）
- 見出し・話者名・「へんじ」・語りの本文の大きさを変えたとき → 祖父母の画面の 360・375 × 640・150% を測り直す（余裕は 4px）
- 親が文字の欄が狭いと言ったとき → 段の欄の高さを見直す（問いかけが見えることと引き換え）

## 人間の決定（2026-11-04。fable-advisor の区切りの全体レビュー 2026-11-03 を受けて）

- 祖父母の「はなす」は、押した瞬間に録音が始まる形のまま
- 祖父母の画面のアルバムに、自分の声の文字起こしが出ることはこのまま。親の試しで嫌がられたら見直す（上の「見直す条件」の 2 つ目）
- マイクの実機での確かめ（すぐ録音の形を含む）は、親の試しのときにまとめて行う
