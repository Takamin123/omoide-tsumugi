# 0003 写真はブラウザ側で縮小し、EXIF は縮小の前に読む

- 日付: 2026-11-02
- 状態: 採用
- 決めた人: 人間（キックオフ時）

## 決めたこと

- 写真はブラウザ側で縮小してから送る
- 撮影日と位置情報は、縮小の前に exifr で読み取り、写真とは別のデータとして送って保存する

## 理由

- sharp は Workers で動かない
- 縮小すると、ふつうは EXIF が消える。このため、縮小の前に読む必要がある
- スマホから原寸の写真を送ると、回線が遅いときに待ち時間が長くなる。また、R2 の容量も増える

## 退けた案とその理由

- サーバー側で sharp を使って縮小する: Workers では動かない
- Cloudflare Images: 使える。ただし、ブラウザ側の縮小で足りるうちは、つなぐサービスを増やさない。ブラウザ側で問題が出たら使う

## 根拠にしたもの

- Workers ではネイティブのモジュールが動かない

## 見直す条件

- 古い端末で縮小が遅すぎる、または HEIC が読めないなど、ブラウザ側の縮小で困ることが出たとき → Cloudflare Images を検討する
