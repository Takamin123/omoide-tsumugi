# 0020 写っているものの正体を問う形も「試す言い回し」として止める

- 日付: 2026-11-03
- 状態: 採用
- 決めた人: fable-advisor に相談（backend-developer）

## 決めたこと

Claude の問いかけを受け取った後の機械的な検査（`src/server/core/claude-checks.ts` の `findTestingPhrase`）で、記憶を試す動詞（覚えて、思い出せ、分かりますか など）に加えて、誰・どこ・いつ・何歳・名前が述語になり、写っているものの正体を答えさせる文末の形も止める。種類は `identify`（ログには種類だけを出す）。

- 止める: 「この人は誰ですか」「これは誰？」「お名前は？」「誰だと思いますか」「これはどこですか」「いつごろの写真でしょうか」「何歳のころですか」
- 通す: 疑問詞が節の中にあり、語りを引き出す問い（「誰と一緒でしたか」「どこへ行った帰りでしたか」）

止まった問いかけは再試行し、二度とも止まれば固定の入り口に倒れる（implementation-policy 2）。

## 理由

- requirements「正解のない、開かれた問いかけにする」。答えが一つに決まる問いは、動詞が「覚えて」でなくても、高齢の家族にとって「覚えていますか」と同じ重さになる
- 0017「写っている人・場所・出来事を言い当てず、指すだけにする」と揃える。言い当てを家族にやらせる問いは、画像解析ツールの振る舞いにも見える
- 迷う言い回しは止める側に倒す。止まっても固定の入り口に倒れるだけで済む。家族に見える前の最後の砦をプロンプトに頼らない（implementation-policy 2）

## 退けた案とその理由

- 動詞だけを止め、誰・どこ・いつはプロンプトで避けさせる: 誤検出は少ないが、qa-engineer のテストで「この人は誰ですか」が実際に検査を通った。最後の砦をプロンプトに頼ることになる

## 根拠にしたもの

- qa-engineer のテスト（`test/qa-claude-calls.test.ts`）で、上の問いが検査を通ることを確かめた
- docs/requirements.md、docs/decisions/0017-entrance-prompt-policy.md

## 見直す条件

- 出し比べで、この種類による停止が原因で固定の入り口の割合が目立って増えたとき（目安 1〜2 割超）。まず入り口のプロンプトで避けさせ、検査は緩めない
- 「〜はどこですか」が、家族の語りを受けて深める開かれた文脈で止まる例が集まったとき。引用の有無で分けるかを考える
