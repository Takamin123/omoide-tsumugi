# 0040 写真を押すと、写真だけの黒い画面で大きく見られる

- 日付: 2026-11-03
- 状態: 採用
- 決めた人: 人間（拡大の画面を作ること、祖父母の画面でも開くこと、閉じるボタン一つ、戻る操作でも閉じる、開く・閉じる動き、めくる機能は今は作らないこと。2026-11-03）。言葉は fable-advisor に相談（frontend-developer）

## 決めたこと

- 写真を押すと、写真だけの黒い画面（拡大の画面）が開く。開く所は祖父母の画面の入り口、家族の画面の今日の入り口、アルバムの帯
- 入り口で「見せたいところ」に寄せている写真も、拡大の画面では写真の全体を出す（寄せは小さい写真にだけ付ける）
- 指で広げる、二度押しで広げる（もう一度の二度押しで戻す）、広げたまま指でずらす。倍率は 1〜4。広げるのは写真だけで、画面全体（ボタンや文字）は広げない（写真の枠で `touch-action: none`）
- 下に横いっぱいの閉じるボタンを一つだけ置く。祖父母の画面は「とじる」、家族の画面は「閉じる」。ほかのボタンや文は置かない。押せるのは閉じるボタンだけなので、Tab でもフォーカスを画面の外へ出さない
- 戻る操作（ブラウザの戻る、Android の戻る）でも閉じる。開くときに履歴を一つ積み、閉じるボタンは履歴を戻して閉じる。Esc でも閉じる
- スマホを横にすると、横長の枠に合わせて写真を大きく出す（向きが変わったら拡大は戻す）。横にした低い画面（高さ 32rem 以下）では、閉じるボタンの段を詰め（高さは主な動作の最低 64px を保つ）、写真に高さを回す
- 押した瞬間に写真を少し沈める（指では :active が付かない端末があるので、pointerdown で印を付ける）
- 動き: 押した写真の位置から画面いっぱいまで広がって開き、閉じると元の位置へ縮んで戻る（FLIP。transform と opacity だけ、0.25 秒）。動きを減らす設定では動かさない
- 画像は今の画像の URL（長い辺 1600px）をそのまま使う。小さい写真と同じ URL なので、読み込み済みの画像から広がる
- アルバムの帯: めくった直後の指離れで開かないよう、帯が止まって今の写真にそろってから 0.25 秒たつまでは開かない。帯の見えていない写真にはフォーカスを渡さない
- 今は一枚だけを見せる。拡大の画面の中でめくる機能は作らない（むすびのときに、見せる写真を並びに替えて足す）
- 読み上げだけの名前: 押せる写真は「写真を大きく見る」（祖父母の画面でも漢字のまま）。拡大の画面は「写真」（アルバムの帯の名前と同じ語）

## 理由

- 写真は家族が語る入り口なので、細かいところ（人の顔、看板の文字）を見たくなる。祖父母の画面でも同じ（人間）
- 祖父母が意図せず開いても迷わないよう、開いたものは同じ写真の大きい姿で、戻り方は一つ（とじる。戻る操作も同じ結果）にする
- 押した写真から広がって戻る動きで、どこから開いてどこへ戻ったかが分かる（implementation-policy「操作に応える手触り」）
- 閉じるボタンは、重なった画面を閉じる動作なので「とじる／閉じる」。「もどる」は家族のことの画面で「前の画面へ」の意味に使っている（fable-advisor）
- 押せる写真の名前は、今日の入り口では周りに「写真」の名前がないので、それだけで意味が立つ「写真を大きく見る」にする。ひらがなの決まりは目で読む語のためのもの（fable-advisor）

## 退けた案とその理由

- 「もどる」: 家族のことの画面の「もどる」（前の画面へ）と意味が重なる
- 読み上げの名前を「大きく見る」: 今日の入り口では何を大きくするか分からない
- 拡大の画面に、ほかのボタン（保存、次の写真）を置く: 戻り方が一つでなくなる。めくるのはむすびで考える
- 画面全体をブラウザの拡大で広げる: ボタンや文字まで広がり、戻し方が分からなくなる
- 拡大用に大きい画像を別に読む: 今の 1600px で足りる。読み込みを待たせない

## 見直す条件

- 親が「とじる」で戸惑ったとき → 語を替える（長くしない）
- 祖父母が意図せず開いて困ることが続いたとき → 祖父母の画面で開く条件（長めに押す、など）を人間に聞く
- むすびで何枚かをめくることになったとき → 拡大の画面に横のめくりを足す（ほかの動作を足すなら人間に戻す）
- 読み上げで、帯の「写真」と拡大の画面の「写真」が続けて読まれて混乱すると分かったとき → 拡大の画面の名前だけを替える
