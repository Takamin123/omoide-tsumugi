# 0034 家族の画面を「今日」「アルバム」のタブにする

- 日付: 2026-11-03
- 状態: 採用
- 決めた人: タブ、帯と語りの連動、横スクロールの例外、矢印、帯の形と条件は人間（2026-11-03、Claude Design の案を見て決めた）。細部（下の「細部」）は fable-advisor に相談（frontend-developer）

## 決めたこと

### 人間が決めたこと
- 家族の画面の下にタブ「今日」「アルバム」。祖父母の画面は変えない。開いたときは常に「今日」（最後に見たタブを端末に覚えない）。今のタブは色だけでなく太さと上の線、aria-current で示す。文字 20px 以上、高さ 64px 以上
- 文字や声で答えている間（入力欄・録音が開いている間）は、タブを描かない
- 今日: 上にメニュー（写真を足す・家族のこと・ほかの人にかわる）、今日の入り口と答え、その下に入り口の写真の語りと返事。語りのある写真の全部の一覧は、今日のタブから無くす
- アルバム: 上にメニューは置かない。上に写真の帯（黒い台紙、白い縁、淡い写真コーナー。横のスクロールスナップ）、その下に左右の矢印（見た目は矢印だけ、読み上げの名前は「左の写真へ」「右の写真へ」。端では押せない）と「4枚のうち 1枚」、下に写真ごとの語りの縦の欄（頭に撮影日と細い線、語りは全文、返事は元の語りの下に左の線で。「返事」の入力欄は一度に一つ）
- 帯の高さは画面の 1/3 程度まで。幅 375px・文字 150% でも語り一つ（話者名＋本文 3 行＋「返事」）が帯とタブの間に見えるよう、写真を縮める
- 連動: 語りを縦に読んである写真の語りが欄の上に来たら、帯がその写真へ一度だけ切り替わる。帯をめくるか矢印を押すと、語りがその写真の頭まで動く。往復はしない（片方を動かしている間はもう片方からの連動を無視する。帯に触れている間は縦からの連動を止める）。動きを減らす設定では動かさずに切り替える。最後の写真の語りまで届く下の余白を置く
- 並びは /api/feed のまま（新しい語りのある写真から）。並び替えは開いたときだけ。返事を送って読み直しても、見ている写真の位置を保つ
- アルバムが空のときは何も出さない（催促や状態の文を出さない）。出すのは家族の語り・返事・撮影日だけ（過去の問いかけ、推測、自動の見出しを出さない）。文字起こしが済んでいない声は再生のボタンだけ
- implementation-policy「横スクロールを作らない」に、アルバムの帯だけを例外とする文を足す

- 0008 の「家族の画面は、自分の今日の入り口を一番上に常に開いて出し、その下に `GET /api/feed` の一覧」のうち、一覧の置き場をこの記録で置き換える（一覧はアルバムのタブへ。今日のタブには入り口の写真の語りだけ）

### 細部（fable-advisor に相談）
- 語りの欄の頭: 撮影日があれば撮影日と細い線、なければ細い線だけ。「撮影日なし」は出さない。欄の各節には読み上げだけの名前として帯と同じ「4枚のうち 2枚」を付け、区切りを伝える
- デモの帯（0008）は各タブのスクロールの一番下に置く（アルバムでは語りの欄の下の余白の中）。タブの上には重ねない。アルバムが空でも出す。祖父母の画面の帯は変えない。デモの時計を進めると画面が作り直されて「今日」に戻る（App.tsx の `key={tick}`）のはそのまま
- アルバムで返事の入力欄が開いている間は、タブと同じく写真の帯（写真・矢印・何枚目か）もたたむ。閉じたら戻し、見ている写真は変えない
- 並びの「開いたとき」は、アルバムのタブを開いたとき。開くたびに /api/feed を読み直し、その順に並べ、前に見ていた写真を ID で探して戻す（なければ一枚目）。開いている間の読み直しでは並べ直さず、増えた写真は末尾に足す。位置を保つのは返事の送信後の読み直しまで（デモの時計を進めたときは作り直す）
- 今日の下の語りには、添える家族の言葉の元の語りも全文で出す
- 言葉: タブ「今日」「アルバム」、何枚目か「4枚のうち 1枚」（写真を足すと同じ形を共有。一枚のときも「1枚のうち 1枚」で、両方の矢印を押せなくする）。読み上げだけの名前: 上のメニュー「メニュー」、タブ「切り替え」、写真の帯「写真」
- 方針の例外の文は、人間が承認した文のうち「「前」「次」のボタン」を「一枚ずつ動かすボタン」に替えて足した。方針にボタンの文字や見た目を書かないため（実装は矢印）。考え方（横の操作なしで全部に届く）は変えていない
- 今日の答えの「声で」「文字で」は今のまま同じ重さ（白い枠）。デザインの案の「声で」を青で塗る形は採らない
- 主な動作の色は #1f4e8c のまま。家族の画面の地は #edeff1（クリーム色にしない）

## 理由
- 語りのある写真が増えると、今日の入り口の下に全部が縦に並び、今日の一枚と過去の語りが混ざる。今日に答える場と、語りを読み返す場を分ける
- 帯と語りを連動させると、写真を見ながら誰が何を語ったかが分かる（写真だけ・語りだけの案では、誰が語ったかか、どの写真かのどちらかが分からない）
- requirements「家族が実際に語った言葉を中心にする。Claude 自身の言葉は最小限」: アルバムに出すのは語り・返事・撮影日だけ。欠けを指摘する「撮影日なし」も出さない
- requirements「高齢の家族は声で答える。他の家族は声か文字で答える」: 家族の画面では「声で」「文字で」を同じ重さに置く。青は送る・録るボタンの色（0028）
- implementation-policy「一画面に主な動作は一つ」「幅 375px で文字を 150% にしても崩れない」: 入力中はタブと帯を下げ、打つ欄を広くする。デモの帯は家族の内容の高さを奪わない所に置く
- 連動の決まりは DOM に頼らない形（src/client/lib/album.ts）に切り出し、Node のテストで確かめる

## 退けた案とその理由
- 案 A 横めくりだけ／案 B 棚と一ページ／案 C 今日＋最近の数枚（人間）: 写真と語りを行き来しにくい、または全部に届かない
- 案ア・イ・ウ（人間）: 情報が多い、または写真だけで誰が語ったか分からない
- 矢印の代わりに「前」「次」の文字（人間）: 新しい順に並ぶので「前」が昔と読まれる
- 今の写真以外の語りを薄くする（人間）: 文字の濃さが下がる
- 「撮影日なし」を出す: 欠けを指摘するアプリの言葉。スマホの写真は撮影日を持たないことが多く、アルバムに「なし」が並ぶ。欄の頭に「2枚目」: 帯の「4枚のうち 2枚」と重なる
- デモの帯をタブの上に固定: 「375px・150% で語り一つが見える」を満たせない。今日のタブだけに置く: 0008 から外れる
- 入力中も帯を残す／写真だけ小さくする: 打つ欄が狭いまま。横に動く領域が入力中も残る。返事の相手は語りで、本文が入力欄の上に見えている
- アルバムを開くたびに一枚目から: 今日で答えて戻るたびに場所を失う。アプリを開いたときだけ並べる: 一日開いたままだと新しい語りが上に来ない
- 引用の元の語りを今日の一覧から除く: 返事の入り口を失う。引用が全文かどうかで出たり消えたりする
- 読み上げの名前を付けない: nav が二つあると区別できない。「タブ」: 画面の仕組みの語
- 方針の文を「前」「次」のまま: ソースと食い違う。「左右の矢印のボタン」: 見た目を方針に書く
- 「声で」を青で塗る（デザインの案）: 「声を主な道にする」は家族の画面の方針にない。青の意味（送る・録る）が薄まる

## 根拠にしたもの
- 手元での計測（qa-engineer、幅 375px・ルートの文字 24px）: 高さ 812 では帯（273px）とタブの間に語り一つが入る（52px 余る）。高さ 667 では写真を下限（3rem）まで縮めても 51px 足りない（帯 231、語りの欄 351、語り一つに要る 402）
- Claude Design の案（今日のタブ、アルバムのタブ。中の家族・写真・語りは架空）。構造・色・大きさ・動きの仕様として使い、文の例と外のフォントは使っていない
- fable-advisor との相談（2026-11-03）
- docs/requirements.md、docs/implementation-policy.md「高齢の人の画面の最低ライン」「家族に見せる言葉」、0008、0027、0028

## 見直す条件
- 高さ 667px 程度のスマホを文字 150% で使う家族がいたとき → 矢印の行の高さや写真の下限を見直す
- むすび（0010）を作るとき → 帯の単位（写真一枚）を替えるか考える
- 親が矢印や連動に戸惑ったとき → 連動の決まり（どこで切り替えるか）や矢印の形を見直す
- 共用の端末が出たとき → アルバムに「ほかの人にかわる」がないことを見直す
- 読み上げで使う家族が、欄の区切りや「切り替え」で戸惑ったとき → 位置の言い方を直す（「なし」には倒さない）
- デモの場で、帯まで毎回スクロールするのが流れを切ると分かったとき → 小さく折りたたむ形を考える（タブの上に常に置かない）
- 「どの写真への返事か分からない」が起きたとき → 動かせない小さな一枚を欄の頭に置くことを考える
- 「返事したのに順が変わらない」と戸惑いが出たとき → 返事の最中には動かさず、戻ったときの並べ直しの合図を考える
- 「同じ文が二度ある」と戸惑いが出たとき → 除かず、元の語りの置き方や印を考える
- 家族がほとんど文字でしか答えず、祖父母が家族の声を聞けていないと分かったとき → 今日と返事の両方で同じに変える。声を主な道にするかは人間が決める
