# 0018 文字起こしの整形と聞き間違いの印

- 日付: 2026-11-03
- 状態: 採用
- 決めた人: fable-advisor に相談（メインの会話）

## 決めたこと
- 整形するのは、声の語りで、文字起こしが終わったもの（kind=voice、transcript_status=done）だけ。文字の語りは整形しない（打った文字が、そのまま本人の言葉）
- 許すのは、句読点と改行を入れることと、意味のないフィラー（「えー」「あのー」）と言い直しの重複を取ることだけ。あとは**削除だけ**にする
  - 許さないこと: 語順を変える、方言を標準語にする、かなを漢字に書き換える、数字の表記を変える（0013）、文法を直す、言い足す、要約する、名前の綴りを直す
- 聞き間違いの印は **cleaned_text の位置** で持つ。Haiku には位置を数えさせない。怪しい部分を決めた記号で囲んだ本文を返させ、アプリが記号を外して start/end を計算する
- 入り口の引用の start/end も cleaned_text の位置（0017）
- 表示では、印の範囲を「……」に置き換える。置き換えはサーバーで行い、クライアントには生の範囲を出さない。記録（records）と文字起こしの keywords（0013）にも、印の範囲の語を使わない
- 検査は全か無か:
  1. 空白・句読点・記号を除くと、cleaned が transcript の部分列（削るだけで作れる）になっている
  2. 除いた後の長さが、transcript の 70% 以上（定数）
  3. 印の範囲が重ならず、文字列の中に収まっていて、合計が cleaned の 30% 以下（定数）
  - どれか一つでも外れたら 1 回だけ再試行する。だめなら cleaned_text は null のままにし、transcript をそのまま印なしで表示する。範囲を指す引用には使わない
- 整形は、文字起こしの直後に、同じ背景処理の続きで一度だけ行う。一度整形した語りは整形し直さない（引用の位置を動かさないため）
- 元の録音と、そのままの文字起こしは残す

## 理由
- 家族に見せる言葉は、家族が実際に語った言葉にする。部分列の検査なら、言い足しも言い換えも、プロンプトに頼らず機械的に止められる
- 方言を残すことは、要件の「方言を考慮する」そのもの
- 表示と引用は cleaned_text を切っている（src/server/routes/views.ts）。印の位置も同じ文字列にそろえる

## 退けた案とその理由
- 印を transcript の位置で持つ: 表示する文字列と位置が合わない
- Haiku に start/end を数えさせる: 外れると「……」が言葉の途中に入る
- 怪しい部分を Haiku に直させる: 推測が家族の言葉に混ざる
- かなを漢字に直すことを許す: 固有名詞を壊す（0013 と同じ理由）
- 整形を毎朝の処理に回す: 10 分の上限を圧迫する。前の夜の語りが整形されないままになり、引用できない

## 見直す条件
- 70% と 30% の定数が、出し比べで実際の語りに合わないとき
- 家族が「文字が違う」と言い、自分で直したいと言ったとき → 誰が直せるかは人間に聞く
- 印の多い語りばかりで、引用を選べないとき → まず文字起こしの側（keywords、prompt）を疑う
