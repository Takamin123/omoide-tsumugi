# 0056 家族の「今日」は日本時間 3:00 で替わる

- 日付: 2026-11-05
- 状態: 採用
- 決めた人: 人間（2026-11-05）

## 決めたこと
- 家族の「今日」（入り口の for_date、語りの for_date）は、日本時間 3:00 で替わる。0:00–2:59 は前の日の続き。毎朝の処理の Cron（UTC 18:00 = 日本時間 3:00）と同じ時刻
- 時間帯は 3:00–10:59 朝、11:00–16:59 昼、17:00–翌 2:59 夜
- 判断はサーバーの src/server/core/clock.ts の appDate と jstSlot。クライアントの裏から前に戻ったときの読み直し（0051）も、同じく 3:00 で一日を替える（src/client/lib/useResumeRefresh.ts の jstDay）
- jstDate（日本時間の暦の日付）は残す。デモの家族の時計の始まりとデモの作り直しの基準日は、暦の日付のまま
- デモの家族の時計（clock を持つ家族）は変わらない

## 理由
- 親の試しの 2 日目（2026-11-05）、夜中の 0:55 に開いた人がいて、その場で固定の入り口が作られた（ensureFixedEntrance）。3:00 の処理はすでに入り口がある人を飛ばすので、その人のその日は Claude の入り口にならなかった。高齢の人は夜中に目が覚めて開くことがある
- 「朝に写真が替わる」のが家族の受け取り方で、0:00 に替わるのは不具合に見える

## 退けた案とその理由
- 0:00–3:00 に開いた人の固定の入り口を、3:00 の処理で Claude の入り口に差し替える: 夜中に見た写真が朝には別の写真になり、答えていた語りの行き先が分かりにくくなる
- 3:00 の処理を 0:00 に動かす: 夜の語りがその日の入り口に入らない。Claude の呼び出しが夜の利用と重なる

## 根拠にしたもの
- 人間の判断（2026-11-05「0時～3時で写真変わるのはバグでは？朝（3時）に変わるはずなのに」）
- 本番の入り口の件数（件数と作られた時刻だけを読んだ）
