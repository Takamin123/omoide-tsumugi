# 0045 声の語りの「聞く」と「返事」を一行に並べる

- 日付: 2026-11-04
- 状態: 採用（「きく」「聞く」の語と、話者名の行に長さを出す形は、次のプレビューで人間に確かめる）
- 決めた人: fable-advisor に相談（frontend-developer）

## 決めたこと

- 声を聞くボタンは一語: 祖父母「きく」、家族「聞く」（長さを入れない）。今日のタブ・アルバム（Narrations）・入り口（EntranceView）で同じ語。流している間は「とめる」「止める」のまま。印（▶）もそのまま
- 誰の声か・長さは「{呼ばれ方}の声（13秒）」（0043 の祖父母の注の文字列そのまま。家族も同じ文字列。呼ばれ方が分からなければ「声（13秒）」、長さが分からなければ「ばあばの声」）
  - 語りでは、声の語りの話者名の行をこの注にする（「ばあば」→「ばあばの声（13秒）」）。行は増えない。文字の語りの話者名は「ばあば」のまま
  - 入り口では、ボタンの横に注（祖父母は今のまま。家族も「ばあばの声で聞く（13秒）」の一つのボタンから、[▶ 聞く] ばあばの声（13秒）の組み立てにそろえる）
- 語りの行は [きく][へんじ]／[聞く][返事] の一行。祖父母の語りの行のボタンだけ、中の横の余白を 1rem → 0.75rem（`.elder .narration > .row > .aux`）。間（0.75rem）、文字、押せる大きさは変えない
- 読む順は変えない: だれが（声・長さ）→ 何を → 聞く・返事
- 置き換え: 0043「語りの欄（祖父母）」の「こえを きく」とそばの注、0028 の家族の「声で聞く（13秒）」「{呼ばれ方}の声で聞く（13秒）」

## 理由

- 祖父母のアルバムの語りの多くは声になる（requirements「高齢の家族も…声で答える」）。前の形では、聞くと返事が縦に 2〜3 段に積まれ、らくらくスマホ（640px 前後・文字 150%）で語り一つ（0041・0043 の基準）が語りの欄に入らなかった（下の「結果」の「前」）。縦に積む限り文字の語りより 86px 以上高く、間を詰めても入らない。入れるには一行に並べるほかない
- 0008「祖父母のボタンは一語のひらがな（動詞）」、0028・0043 の見直す条件「語を替える（長くしない）」。「きく」は「はなす」「かく」の列に並び、短くなる方向
- 0043「同じものに同じ形を一つ」「家族と祖父母の違いは大きさだけ」: ボタンの語は画面ごとに一つ、注の文字列は一つ（今あるもの）、置き方の決まり（語りでは話者名の行、入り口ではボタンの横）は両画面で同じ
- 新しい固定の言葉を増やさない: 注は今ある文字列の使い回し。文字起こしが pending / failed の声（本文なし）も「ばあばの声（13秒）」→[きく][へんじ] で、案内の文なしに何かが分かる（0008）
- 余白はボタンの中を詰める。隣との間は最低ライン（8px）に近い数値なので触らない

## 退けた案とその理由

- 何も変えず記録だけ: 親の実機の主な場合で基準を満たさない
- 大きい文字のときだけ聞くボタンを話者名の横に: 幅に入らない（81 + 18 + 248 > 300）
- 狭い幅のときだけ見た目を短く出し分ける: 見える文字と読まれる文字が違う（0041 で避けた）。同じボタンが二通り
- 注を独立の行に: 41px と間が増え、入らない（−55 前後）
- 注を「声（13秒）」だけ: 0043 で退けた（語として立たない）。今の文字列との差は「の」と名前で、幅の得が小さい
- ボタンを名詞「こえ」: 動詞の列（0008・0043）から外れる
- 間を 0.5rem に詰める: 最低ラインに近い数値を削る
- 「へんじ」「返事」の文字を小さく: 20px の下限に触れる

## 根拠にしたもの

- fable-advisor との相談（2026-11-04）
- 手元での実測（架空の家族、playwright の電話の画面を幅 360・375px、高さ 640・667px に、ルートの文字 16・20.8・24px。タブレットは 1180 × 820）。手元のデモの声は長さ（duration_ms）がないため、「（13秒）」は画面の文字を書き換えて測った。新しい形は、開発サーバーの画面に同じ文字と CSS を当てて測った
- 0008、0028、0041、0043、docs/implementation-policy.md「高齢の人の画面の最低ライン」
- 実装: src/client/words.ts（listen、listenNote）、src/client/parts/Narrations.tsx、src/client/parts/EntranceView.tsx、src/client/styles.css（`.elder .narration > .row > .aux`）

## 見直す条件

- 親が「きく」で戸惑う・「尋ねる」と読んだ → 語を替える（長くしない）。候補は人間に戻す
- 実際の家族の呼ばれ方が長く（12 字以上）、150% で話者名の行が折れる → 語りの注だけ名前を落として「声（13秒）」にする（0043 の見直す条件と同じ）。入り口は名前を残す
- 家族の画面で「聞く」だけでは何を聞くか分からないと言われた → 家族の入り口だけ文のボタンに戻すかを考える（語りは一行の制約があるので戻さない）
- 話者名の行・補助のボタン・見出しの高さを変えたとき → 祖父母・家族の 360・375 × 640・150% を声の語りでも測り直す
