# 0061 画面の見直しのモックの言葉と飾り（「今日の問いかけ」、話者の頭文字の丸、「新しい」の札）

- 日付: 2026-11-05
- 状態: 採用
- 決めた人: 人間（2026-11-05。「今日の問いかけ」と話者の頭文字の丸を入れる、「新しい」の札と強調を入れる、そのほかのモックの言葉は入れない。丸の条件: 色は人ごとに安定・字と地のコントラスト 4.5:1 以上・色だけで区別させず名前を必ず並べる・頭文字は呼ばれ方の最初の一字）。細部は fable-advisor に相談（frontend-developer）。見直しの 6 点は [0059](0059-screen-refresh.md)

## 決めたこと

### 入れるもの
- **「今日の問いかけ」**: 両画面とも、問いかけのカードの先頭に補助の大きさの青い太字で一行（札・箱にしない）。祖父母は祖父母の補助の大きさ。固定の入り口（問いかけが null）でも出す。「読み上げ」ボタンは今の位置（問いかけの下、「AI の声で読みます」と一緒）のまま。読み上げから隠さない。文字列は words.ts に一つ（両画面同じ語）
- **話者の頭文字の丸**
  - 色: 淡い地＋濃い字の組を 6 つ持ち、家族の中の人の並び（members。サーバーは作った順に返す）の番号で順に割り当てる。7 人目からは先頭に戻る。淡い青の組は使わない（「聞く」「読み上げ」の丸いボタン、返事のタブの新しい返事の地と紛れる）。地と字の 4.5:1 はテストで固定する
  - 字: 呼ばれ方の最初の一つの文字のかたまり（結合文字・絵文字を割らない）。先頭の空白・記号は飛ばし、英字は大文字に。「お」「ご」を飛ばす・続柄から取る・字を変換することはしない（「お母さん」は「お」）
  - 置き場: 話者名の行の中、名前の左。本文の左の列には置かない（モックの形は採らない）。大きさは話者名の行の高さを上限にする（文字は小さくしない）。返事の丸も同じ大きさ
  - 出す場所: 語りと返事（今日・アルバム・返事のタブ）、入り口の添える家族の言葉の話者名。出さない所: 祖父母の今日の答えのボタンの上の「今の話者の呼ばれ方」、入り口の声の注（同じ箱の中の二度目の名前）、言葉の糸のボタン、家族のことの人の一覧
  - 読み上げ: 丸は aria-hidden（名前が必ず並ぶ）
  - 色と字は一か所（`src/client/lib/initials.ts`）で members から求め、語りと入り口が同じ関数を使う
- **返事のタブの「新しい」**: 開いた時点でまだ見ていなかった語り（0058 の未読と同じ決まり）の箱を、淡い青の地と枠（人間の決定 2）にし、見える札「新しい」（タブのバッジと同じ青地に白、補助の文字の大きさ）を話者名の行に置く。隠した文は足さない（札がそのまま読まれる）
  - 強調はそのタブを開いている間だけ。次に開くと、その時点の未読だけが強調される。開いている間に届いたものは強調しない（0058「見たことにしない」と同じ扱いで、次に開いたときに強調される）
  - 0058「まだ見ていなかったものの印は付けない」を、これで置き換える
- 下のタブの印（今日=太陽、アルバム=写真、返事=吹き出し）と、アルバムの何枚目かの下の点。どちらも飾り（aria-hidden）で、語はそのまま

### 入れないもの
- 今日のタブの語りの上の見出し「みんなの言葉」
- 画面の頭の行（家族の「今日 11月5日（水）・お母さん」、返事の「返事 / あなたの言葉と写真に届いたもの」、祖父母の日付）。家族の今日は今の上のメニュー（写真を家族に共有する・家族のこと）、祖父母は今の呼ばれ方の行のまま
- 自分の語りの話者名「あなた」（呼ばれ方のまま）
- 何枚目かの「2 / 4」（「4枚のうち 2枚」のまま）
- 声の注の「じいちゃんの声・12秒」「じいちゃん・声 12秒」（0045 の「じいちゃんの声（12秒）」のまま）
- 送った後の流れ（送った声の文字起こしを出し、話す・書くを省く形）。人間が決めていない（0059）

## 理由
- 「今日の問いかけ」は、問いかけ（Claude の推測の枠）を紙の色の家族の言葉から名前で分ける（requirements「家族が語ったことと Claude の推測をはっきり分ける」）。札にすると祖父母の画面で隣の淡い青の丸いボタンと紛れる。固定の入り口で消すと「今日は作れなかった」が画面に漏れ、仕組みを前に出す。読み上げを見出しの右に移すと「AI の声で読みます」（0019・0027）と離れ、祖父母の今日の段の高さが動く
- 丸の色: 並びが安定し人を消す機能がない今は、番号で「人ごとに安定」を満たす。id のハッシュは 5 人を 6 色に割るだけで 9 割の確率で重なり、見分ける役目を果たさない
- 丸の字: 「お」「ご」を飛ばすのは敬称かどうかの推測で、「おさむ」「ごろう」を壊す。アプリは家族の言葉に手を加えない。人間の条件「最初の一字」のとおり
- 丸の置き場: 本文の左に列を作ると本文の幅が減って行が増え、祖父母の 360px・150% の高さの約束（0043・0045）が崩れる
- 「新しい」の札: implementation-policy「色だけで意味を伝えない」。淡い青と紙の色の差は小さく、隠した文は読み上げの人にしか届かない。タブのバッジの数と札の数が対応し、どれが新しいかを探せる。起きたことを言う一語で、相づちや感想ではない
- 入れないもの: requirements「Claude 自身の言葉は最小限」。「みんなの言葉」は 0008・0034 の見出しなしで、一人しか語っていないとき不正確。画面の頭の日付は写真の記録の日付（0047）やデモの時計（0008）と二重になる。返事の頭の文は 0058「知らせの文・まとめを足さない」。「あなた」はアプリが家族に話しかける二人称。「2 / 4」「・12秒」は同じものの二通りの形（0043）

## 退けた案とその理由
- 色を id のハッシュで決める（少人数で重なる）、色を 8〜10 に増やす（4.5:1 と見分けやすさの両立が難しい）
- 頭の「お」「ご」を飛ばす、続柄から取る、二字にする
- 丸を本文の左の列に置く（モックの形）、行の右端、狭い幅で丸を消す、返事の丸だけ小さく
- 見出しを「問いかけ」だけにする、固定の入り口で消す、祖父母だけ札にする、読み上げを見出しの右に置く
- 「新しい」を色と隠した文だけにする: 目で見る人には色だけになる

## 見直す条件
- 7 人以上の家族で同じ色の二人が同じ写真に並ぶのが目に付く → 色を足すか、未使用の色を優先する割り当てに
- 人を消す・並べ替える機能ができた → 色を id に紐づけて保存する
- 同じ字の人が一家族に 3 人以上 → 色で足りるか人間に見てもらう。敬称を飛ばすかは人間が決める
- 丸で祖父母 360px・150% の声の語りが高さの約束を破る → 丸を行の高さより小さく。それでも破れば 0045 の条件どおり注を「声（13秒）」に
- 親が丸を押そうとした → 丸の地を紙の色に近づけるか外すかを人間に戻す
- 「今日の問いかけ」を親が読まない → 語を替える（札にはしない）
- 札が 360px・150% で話者名の行を崩す → 札の位置を見直す（色だけには戻さない）
- タブの印で 360px・150% の「アルバム」が折れる、帯とタブの間の「語り一つ」が入らない → 印を小さくするか外す（文字・高さは下げない）
