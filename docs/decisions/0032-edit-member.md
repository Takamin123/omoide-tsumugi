# 0032 「家族のこと」で登録した一人ひとりを後から直す

- 日付: 2026-11-03
- 状態: 採用（「自分自身も同じく直せる。画面を祖父母向けに直すと…」の段は 0036 で置き換え済み。自分の画面は自分で直せない）
- 決めた人: 人間（直す機能を足すこと、直せる欄、消す機能は作らない）。形と言葉は fable-advisor に相談（frontend-developer）

## 決めたこと
- 一覧の一人ひとりのカードの右下に補助の大きさのボタン「直す」。押すと今の内容が入った入力欄（MemberForm を足すときと共用）がカードの中に開く。送るボタンは主な動作の見た目で「直す」、その下に「やめる」。保存したら一覧を読み直して閉じる。開くのは一度に一人
- 直せるのは、家族の中での立場、呼ばれ方、画面、話し方と地域。setUpByMemberId は今の値のまま送る。人を消す機能は作らない
- 入力欄が開いている間は「家族を足す」の節と、ほかの人の「直す」を隠す。閉じたら戻す。「家族を足す」は外さずに隠し、入れかけの内容を残す
- 「直したら、これから先に使われる」の補助の文は添えない
- 自分自身も同じく直せる。画面を「祖父母向け」に直すと、もどった先は祖父母の画面になる。案内や確認は出さない

## 理由
- 固定の言葉は最小限（0008）。呼ばれ方を直すと引用の話者名などは新しくなり、文字起こし済みの本文だけが古いまま残るので、「これまでの語りは変わりません」は正確でない。正確に書くには仕組みの語が要り、「使います」の主語は AI になる（implementation-policy「AI の存在を前に出さない」）
- 画面（role）は事実で、表示は事実に従う（0008 の setUpBy と同じ倒し方）。取り消せる操作に確認は要らない
- 「直す」を補助の大きさにし、開いている間は「足す」を隠すのは、implementation-policy「一画面に主な動作は一つ」
- 開いている間にほかの人の「直す」を出さないのは、入れかけの内容が消える道を作らないため

## 退けた案とその理由
- 開いた入力欄の中に「これから先の語りに使います。これまでの語りは変わりません」: 半分だけ正しい文になる。主語が AI
- 一覧の上に常に補助の文を出す: 開かないときにも読む量が増える
- 開いている間も「足す」の欄を残す: 主な動作が二つ見え、直し終わったつもりで「足す」を押す取り違えの道ができる
- 「直す」を主な動作の見た目で並べる: 人数ぶん青が並び「足す」が埋もれる
- 自分の画面だけ直せなくする: 人間の指示と逆。祖父母のタブレットを家族が整える場面で要る
- 「もどると祖父母の画面になります」の案内: 予想を固定の言葉にする

## 根拠にしたもの
- fable-advisor との相談（2026-11-03）
- docs/requirements.md「記録と言葉」、docs/implementation-policy.md「高齢の人の画面の最低ライン」「家族に見せる言葉」、0008、0013、0028

## 見直す条件
- 実際の家族が「地域を直したのに文字が前のまま」で戸惑ったとき → 文を足す前に、文字起こしのやり直しを考える（費用がかかるので人間が決める）
- 自分を祖父母向けに直して、その端末から「家族のこと」に戻れなくなった人が出たとき（祖父母の画面には「家族のこと」への入り口がない） → 祖父母の画面から「家族のこと」へ行く道を作るかを人間に聞く
- 人を消す必要が出たとき → 0031（家族の場をまるごと消す）との関係を人間が決める

## 見直し（2026-11-03）
- 自分の画面（祖父母向け／スマホ）は自分で直せない（0036。人間の決定）。自分のカードの「直す」では「画面」の欄を出さない。ほかの欄は自分でも直せる。サーバーも自分の role の変更を 403 にする
- 直した後に家族の画面の人が一人もいなくなる変更も 403（0036）
- 入力欄が開いている間は、ほかの人の「直す」に加えて「リンクを作る」「リンクを作り直す」も出さない（0036）
