# 0037 二人で使う端末は、一人として登録する

- 日付: 2026-11-03
- 状態: 採用
- 決めた人: 人間（2026-11-03）。記録は fable-advisor に相談（backend-developer）

## 決めたこと

- 祖父母が二人で一台のタブレットを使うときは、「じいじとばあば」のような一人として登録してよい。その一人のリンクをタブレットで開く
- コードは変えない（一人ずつのリンク 0036 のまま。人の数や名前に決まりは足さない）
- 語りの話者は、その一人（「じいじとばあば」）になる。どちらが話したかは分けない

## 理由

- 0036 で端末と人を結びつけ、「ほかの人にかわる」をなくした。共用の端末で話す人を切り替える手段は無くなる
- 二人で並んで写真を見て、どちらともなく語るのが共用の端末の使い方。話す前に切り替える一手を求めない方が、アルバムを囲む場に近い
- 呼ばれ方を家族が自由に付けられるので、「じいじとばあば」で家族には誰の語りか分かる

## 退けた案とその理由

- 共用の端末にだけ「ほかの人にかわる」を残す: 0036 でなくした切り替えが、裏口として残る。高齢の家族に切り替えの一手を求める
- 一台の端末に二人のリンクを持たせる（cookie を二つ）: 合言葉の確認が「どちらの人か」を決められなくなる

## 根拠にしたもの

- 0036、0008（祖父母のタブレットの話者の切り替え。0036 で置き換え）、0010

## 見直す条件

- 家族から、共用の端末で話す人を分けたいと言われたとき（入り口を一人ずつに作りたい、方言が二人で違う、など）
- 方言の設定（文字起こしの prompt）が二人で違い、文字起こしの質が下がったとき
