# 0010 データの形の骨格と、推測を分けて持つ線の引き方

- 日付: 2026-11-02
- 状態: 採用（「合言葉は家族単位」の段は 0036 で、「confirmed と rejected は根拠の語りを持つ」の段は 0044（決めた人と時刻を持つ）で置き換え済み）
- 決めた人: 人間（要素の列挙、むすびの定義、位置の丸め、写真の登録は本人だけ）、fable-advisor に相談（メインの会話）

## 決めたこと

- 表は families / invite_links / members / photos / photo_guesses / narrations / records / musubi / musubi_photos / entrances。列の定義はソース（`src/server/db/schema.ts`）を正とする
- 家族が語ったことと Claude の推測は、別の列・別の値で持つ。推測には必ず model と prompt_version を付け、CHECK 制約で縛る。どの表にも family_id を持たせる
- **むすび**は、家族それぞれのライブラリにある写真と、その写真についての語りを「同じ出来事（同じ日・同じ場面）」としてまとめる結びつき。一つのむすびが「その日のアルバム」の一ページになる。語りは写真を通してむすびに入る。状態は写真ごとに guessed / confirmed / rejected で持ち、confirmed と rejected は根拠の語りを持つ
- 人・場所・時期・出来事の記録と写真の結びつきは、むすびとは別に、記録の側（`records.photo_id`）で持つ
- 緯度経度は生で持たない。ブラウザで小数第 2 位（約 1 km）に丸めてから送り、サーバーでも丸め済みかを確かめて、そうでなければ受け取らない。クライアントには位置の有無だけを返す
- 合言葉は家族単位。本人は家族の場に入った後に選び、端末が覚える。「誰の写真か」「誰が語ったか」は家族の中での自己申告で、家族の信頼の上に立つ。サーバーは家族の中なら誰の ownerMemberId・speakerMemberId でも受ける。画面で写真を登録できるのは本人の分だけ
- 家族同士のやり取りも語りと同じ表に入れ、`reply_to_id` で返事を表す
- 祖父母の画面で入り口がないときは、何も出さない（祖父母には写真を足す手段がない）

## 理由

- 家族が語ったことと Claude の推測を分ける（requirements）。家族の言葉が上書きされず、機械の産物に model と prompt_version が付き、名前で分かること
- 推測は問いかけの形でしか使わない。家族が「違う」と言ったことを覚えておかないと、同じ問いが繰り返され、試す問いかけに見える
- 一台のタブレットを祖父母二人で使うので、合言葉で本人を決めると切り替えられない
- Claude に生の緯度経度を渡さない・ログに出さない（実装の方針）。使い道に無い精度を本番に置かない。入る時点で丸めれば抜けが無い
- AI は黙って「語り」を記録し翌日に活かす。返事も翌日の材料としては語り

## 退けた案とその理由

- むすびを記録と写真の結びつきとする: 人間の意図と違った。記録と写真の結びつきは records の側で足りる
- 本人ごとの合言葉: 共用タブレットで切り替えられない
- 緯度経度を生で持ち、出すときだけ丸める: 出す場所ごとに丸めを書くと、一か所抜けたら生の値が出る
- 位置の有無だけ持つ: 同じ場所の写真をまとめられない
- やり取りを別の表にする: 作品に無い区別を作り、引用元が二か所になる

## 根拠にしたもの

- docs/requirements.md「守る方針」、docs/implementation-policy.md 1・2・4、0003、0008、0009

## 見直す条件

- 約 1 km の丸めで足りなくなったとき（生の値を持つ側には倒さず、まず家族の言葉で分けられないかを考える）
- 自己申告では困る場面（家族の中での取り違え、なりすまし）が出たとき
- 家族が語りの文字を直したいと言ったとき（誰が直せるかを人間に聞いてから列を足す）

## 追記（2026-11-04）: 「今日」に写真がないときは一行出す

- 人間の決定: 「今日」に出す写真がない（家族の写真がまだ一枚もなく、入り口が作れない）ときは、何も出さないのをやめて一行出す。空の画面では、壊れているのか待てばよいのか分からないため
- 家族の画面: 「まだ写真がありません。「写真を家族に共有する」から写真を入れると、ここに届きます」（上のメニューと同じ名前で、できることを言う）
- 祖父母の画面: 「まだ写真が届いていません。家族が写真を入れると、ここに出ます」（祖父母には入れる手段がないので、入れ方は言わず、待てばよいことだけを言う。催促しない）
- 読み込みに失敗したときは今までどおり失敗の文だけを出し、この一行は出さない
