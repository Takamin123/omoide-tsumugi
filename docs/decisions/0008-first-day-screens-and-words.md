# 0008 初日の土台の画面の流れと、家族に見せる固定の言葉

- 日付: 2026-11-02
- 状態: 採用（「/ で選び端末に覚える」の段と、祖父母のタブレットの話者の切り替えは 0036 で置き換え済み。「祖父母の画面に文字起こしは出さない」と、祖父母の画面の形（家族の画面と同じ形にした）は 0043 で置き換え済み）
- 決めた人: fable-advisor に相談（frontend-developer）。デモの操作を出す条件（canAdvanceClock）は人間

## 決めたこと

- `/start` は運営だけが使う小さな画面。運営の合言葉を入れて家族の場を作り、招待リンクを一度だけ見せる。運営が写して始める人に渡す。家族の画面からはつながない。運営の合言葉は端末に保存しない。デモの家族として作るかの選択はここに置く
- `/join/<token>` で cookie を得て `/` に置き換える（URL から合言葉を消す）。`/` で「あなたはどなたですか」を選び、端末に `{ familyId, memberId }` の組で覚える。開いた家族と違えば捨てる
- `setUpByMemberId` は事実のまま。自分で足したら null、ほかの人を足したら足した人の ID
- 祖父母のタブレットは今の話者だけ覚え、elder 全員を大きなボタンで並べる。elder が一人なら切り替えを出さない。今の話者の呼ばれ方はマイクの近くに常に見せる
- 録音は二度押し（「はなす」→「おわる」で送る）。送る前の確認はしない。ごく短い録音（押し間違い）は何も言わずに捨てる。送れなかったら録音を手元に残し、同じ場所のボタンで送り直せる（同じ requestId）。祖父母の画面に文字起こしは出さない
- 家族の画面は、自分の今日の入り口を一番上に常に開いて出し、その下に `GET /api/feed` の一覧。見出しは付けない。文字起こしが pending / failed の声は再生だけで、案内の文は出さない。返事は語りごとに文字か声（replyToId を付け、entranceId は null）。入り口がなければ枠を出さない（催促の文を出さない）
- デモの操作は `family.canAdvanceClock`（サーバーが決める）のときだけ、どの画面でも下の帯に出す。録音済みファイルの送信は祖父母の画面の帯にだけ置き、マイクと同じ送る関数に渡す。false のときは帯を描かない
- 固定の言葉は `src/client/words.ts` に集める。祖父母の画面のボタンは一語のひらがな、文はふつうの漢字かなまじり。家族の画面は大人向けのふつうの日本語。「！」、絵文字、相づち、お礼、「AI」「分析」「処理中」を出さない。添える言葉には話者の呼ばれ方を添える
- 主な言葉: 「あなたはどなたですか」「この中にいません」／「はなす」「おわる」「おくりました」「おくれませんでした。もういちど おしてください」／「返事」「文字で」「声で」「送る」／「写真を選ぶ」「12枚のうち 5枚」「登録した写真」「すでにある写真」「読めなかった写真」／「家族を足す」「続柄」「呼ばれ方」「画面（声で答える大きな画面（祖父母向け）／スマホの画面）」「話し方」「地域」／「家族に送るリンク」「作り直す」と、作り直す前の「いまのリンクは使えなくなります。いまのリンクで開いている端末（タブレットなど）は、新しいリンクで開きなおしが必要です」／エラーは unauthorized「リンクを開きなおしてください」、not_found「見つかりませんでした」、too_large「大きすぎて送れませんでした」、そのほか「うまくいきませんでした。もう一度お試しください」

## 理由

- デモの操作はブラウザで完結させる（requirements「デモ用のボタン」）。`/start` は既存の Bearer 付き API を使いやすくしただけで、攻撃の面は増えない。運営の合言葉を見るのは運営だけ
- 誰が語ったか・誰が設定したかは出所そのもの。予想を記録に混ぜない。話者の取り違えを防ぐため、今の話者を常に見せる
- 「一画面に主な動作は一つ」。録音の確認や話者の組の設定は、初日の土台に要らない
- 画面の言葉は家族の言葉を中心にし、仕組みの状態（文字にしています）や相づち（ありがとう）を出さない。起きたことだけを言う（「おくりました」）
- 今日の入り口が作品の中心なので、一覧の中に隠さない

## 退けた案とその理由

- 家族の場は curl だけで作る: 今日のゴールが画面に見えず、デモが二つの道具にまたがる
- 祖父母のときだけ setUpByMemberId を入れる: 「あとで直すだろう」という予想を記録に入れることになる
- 端末で祖父母の組を覚える: 設定の手順が増える。今日は一組の祖父母だけ
- 押しっぱなしの録音: 高齢の人に難しく、タッチの取りこぼしもある
- 止めた後に「送る／やり直す」: 動作が三つになり、話す前に構えさせる
- pending に「文字にしています」を出す: failed のときに失敗を知らせるか、ずっと出し続けるかになる
- 入り口を「今日の一枚」として開ける形: 中心が隠れ、掲示板に見える
- デモの操作を `?demo` や `/demo` に置く: URL の置き換えで消える／話者と入り口を選び直すことになり、取り違えの道ができる
- 「とどきました」「ほかの人」「答え方」: 起きたこと以上を言う／意味が曖昧／role の意味とずれる

## 見直す条件

- 家族自身が家族の場を作る必要が出たとき → 申し込みの形を人間が決める
- 離れて住む二組の祖父母がいる家族が出たとき → 端末で祖父母の組を覚える
- 使ってもらって「止め方が分からない」「送りたくないものが送られた」が起きたとき → 「やり直す」だけを足すことを考える（0050 で置き換え: 送った直後の声に「とりなおす」を出す）
- ボタンの語が伝わらなかったとき → 語を替える（長くしない）
- デモの帯が祖父母の画面で邪魔と分かったとき → 初期状態でたたむ

## 追記（2026-11-04）: 家族の画面も一押しで録り始める

家族の画面の「声で話す」も、祖父母の画面の「はなす」と同じく、押すとその場で録り始める形にそろえた。前は声の段に移るだけで、もう一度「話す」を押すまで録り始めず、分かりにくかった（人間が本番で使って気づいた）。送れなかった声が残っているときだけは録り始めず、「送る」で送り直す段に移る（録音が見えないまま始まらないように）。

## 追記（2026-11-04）: マイクの許可を待っている間の表示

- 決めた人: fable-advisor に相談（frontend-developer）

「声で話す」「はなす」を押してからマイクの許可が下りるまで（許可済みなら 0.1 秒前後、初回は許可のダイアログの間）、録るボタンが押せる顔のまま残り（家族は「話す」、祖父母は「はなす」「かく」）、もう一度押せと見えていた。待っている間は、録るボタンの場所を押せない形（aria-disabled でフォーカスは残す。押せる青をやめて白地に点線の枠。文字は薄くしない）にして、「マイクを準備しています」（家族。下に「やめる」）／「マイクを じゅんびしています」（祖父母。「おわる」と同じ横いっぱいの一つに替え、「かく」は待つ間出さない。下に「やめる」）を出す。録り始めたら同じ場所が「終わる」「おわる」になる。文字は主な動作の大きな語ではなくふつうの大きさで、「マイクを」の後（祖父母は「じゅんび」の後も）でだけ折る（幅 360・375px、文字 150% で、今日の答えは二行、祖父母の語りの返事の欄は三行。語の途中では折れず、横のはみ出しなし）。

- 「やめる」は今日の答え（ふだんは「やめる」がない）でも、待っている間は出す。許可の表示を選ばずに閉じると決着しないまま残るブラウザ（Firefox）があり、抜け出す道がなくなるため（qa-engineer・code-reviewer の指摘。言葉は今ある「やめる」）

- 「かく」を消すのは、待つ間に文字の欄へ移ると録音が見えないまま始まりうるため（上の追記と同じ理由）。送れなかった声が残っているときは録り始めない振る舞いは変えない
- 退けた案: 「準備中」「じゅんび」（何の準備か分からず、一語は押せる動詞に見える）、色だけ落とす（なぜ押せないか分からず壊れたように見える）、0.3 秒たってから文字を出す（仕組みが増え、初回の最初が色だけになる）
- 待っている間に「やめる」を押したら、許可待ちの決着を待たずにすぐ押し直せる。やめた試みが後で決着しても、録音は捨ててマイクを閉じる（src/client/lib/mic-start.ts。試みごとに番号を持つ）
- 実装: src/client/lib/mic-start.ts、src/client/parts/VoiceRecorder.tsx（useRecorder の starting）、src/client/parts/ReplyBox.tsx、src/client/words.ts（micWaiting）、src/client/styles.css（.mic-waiting）。テスト: test/client/mic-waiting.test.ts
- 見直す条件: 親の端末で、許可済みのときの短いちらつき（今も「話す」→「終わる」で起きていたもの）が目に付く → 文字だけ 0.3 秒遅らせる。初回の許可待ちで「やめる」を押して戻ってしまう人がいた → 「マイクの許可を確かめています」のような言い方に替えるかを人間に確かめる
