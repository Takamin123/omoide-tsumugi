# 0062 審査員の案内ページ（/demo/<鍵>）

- 日付: 2026-11-06
- 状態: 採用
- 決めた人: 人間（パスワードなし、4 人のリンクを並べて押すとその人になる、帯の時計は審査員も押せる、秘密の値を消すだけで閉じる。2026-11-06）。文・守り・待ちの表示は fable-advisor に相談（frontend-developer）

## 決めたこと

### 入り口と鍵
- 審査員は `/demo/<鍵>` を開く。ページは `POST /api/demo/guide { key }` で 4 人の合言葉を受け取り、`/join/<合言葉>` へのリンクを同じタブで並べる。鍵は URL の検索語ではなく本文で送る
- `POST /api/demo/guide` は PUBLIC_ROUTES に置き、入り口の中で本文の鍵を時間一定で比べる。設定なし・鍵の不一致・形の違いは、区別せず 404。応答は `Cache-Control: private, no-store`。鍵とリンクをログに出さない
- 秘密の値は二つ。`DEMO_GUIDE_KEY`（32 文字以上、URL に載る文字だけ。短い・ほかの鍵と同じなら設定なしとみなす。0030 の規則）と `DEMO_GUIDE_LINKS`（JSON。台本の 4 人の呼ばれ方 → 合言葉）。プレビューだけに登録し、本番には登録しない（0038 の追記と同じ）
- 合言葉はサーバーから引けない（平文で保存しない。0036）ので、人間が秘密の値に入れる。URL ではなく合言葉だけを持つので、別の環境の URL を載せ間違えない
- リンクは返す前に一つずつ findActiveLink で確かめ、デモの家族の、その呼ばれ方の人のものだけを返す。使えない人のボタンだけ出さない（ログは種類と人の ID だけ）。全員使えないときは 404
- ページ側: 404 なら `/` に置き換える（ほかの知らない道と同じに見え、鍵を URL に残さない）。`noindex` と `no-referrer` の meta を置く。外のものは読み込まない

### 守り
- 案内が開いている間（鍵とリンクの設定がどちらも使える間）、デモの家族の `POST /api/members`（最初の人のほか）・`PATCH /api/members/:id`・`POST /api/members/:id/link` は 403。画面は既存の「この端末からはできません」でボタンは隠さない。ページの注意に一行書く
- 運営が人やリンクを直すときは、先に秘密の値を消す。止まるのは台本の 4 人の家族だけでなく、その環境のデモの家族すべて（デモの家族を新しく作る手順も、2 人目で 403 になる）。手元の `.dev.vars` には常時は入れない

### 文
- 文は `src/client/demo/guideWords.ts`（読むのは審査員なので words.ts に入れない。0014 と同じ考え方）。画面にある名前は words.ts から差し込む
- 「入り口」は使わず「写真と問いかけ」と言う。Claude の役割は「毎朝、一人ひとりに写真と問いかけを一つ届けます。語り合いには割り込みません」の一文で言う（審査員が見るべき点なので、家族の画面と違って Claude の名を出す）
- 手順 2 は断定し、「届いていなければ『アルバム』に出ています」を添える。前の審査員が時計を進めた後は、じいちゃんの写真の持ち主がお母さんとは限らない（0058 の (a)(b)(c)）
- 注意と提出フォームの文は「話した声・書いた文字・入れた写真は、次に見る方にも届きます」でそろえる
- 同じブラウザでは一度に一人。cookie が一つなので、別のタブを開くと、前のタブは見た目がそのままでも、押した人として動く（手元で確かめた: じいちゃんの見た目のタブから送った語りの話者がお母さんになる）

### 帯の待ち
- 夜 → 翌朝を押している間だけ、帯に「進めています」（words.demo.advancing）を出す。朝 → 昼 → 夜は 0.02 秒で終わるので出さない。実測 71〜78 秒（手元、本物の Claude）
- 進めている間の状態は App が持つ。帯はタブごとに描き直されるので、帯に持つと、待ちの間にタブを替えたときに表示が消え、ボタンがまた押せるようになる（qa-engineer が見つけた）。押し直すと、毎朝の処理の最中に時計がさらに進む
- 「進めています」を出すかは、押したときの時間帯で決める。サーバーは毎朝の処理の前に時計を保存するので、待ちの間に読み直すと時計はもう朝になっている（「家族のこと」を開くと読み直す）。読み直しが終わるまでボタンは押せない（古い時計のまま二度押しさせない）

## 理由
- 提出フォームの欄は「審査員用リンク」一つと 150 文字。ログイン情報を渡さずに、4 人を行き来できる形が要る
- 初期化（0038）は人とリンクに触れないので、審査員が「リンクを作り直す」や呼ばれ方の変更を押すと、初期化では戻せず、一人の操作が全審査員と提出済みのリンクに効く
- 一人分のリンクの不備でデモ全体を落とさない。実際の家族のリンクを返さない守りはサーバー側にある
- implementation-policy 1「1 秒を超えうるときは、何をしているかを出す」。帯を見ている瞬間に案内は見えていない
- 審査員の写真がほかの審査員に見えることは、プライバシーの方針に照らして先に言う

## 退けた案とその理由
- 鍵を GET の検索語で送る: Workers のログや履歴に残りやすい
- 注意書きだけで家族のことを守る: 読まれない前提で考える。何もしない: 提出中の事故に戻す道がない
- リンクが一つ使えないときにページごと 404: 設定ミス一つで何も見られなくなる
- リンクを URL で持つ: 別の環境の URL を載せ間違えても気づけない
- 待ちの表示を案内の説明だけで済ませる: 上のとおり

### 新しい家族
- 案内に「新しい家族を作る」。専用の画面 `/demo/<鍵>/start` は説明の一文と「作る」「もどる」だけ（合言葉の欄、デモの印、初期化の欄は出さない）。`POST /api/demo/guide/families { key }` を PUBLIC_ROUTES に足し、鍵の扱いは `/api/demo/guide` と同じ（設定なし・不一致は区別せず 404、鍵をログに出さない）。ふつうの `/start`、`POST /api/families`、初期化は変えない。本番には鍵がないので閉じている
- 作った家族は is_demo 真で時計つき（帯が出て、Cron の対象から外れる）。合言葉は cookie にだけ置き、リンクの画面を挟まず最初の人を入れる画面へ進む
- 印は `families.name = 'demo-guide'`（今は常に null で画面に出ない列）。移行を足さない。数えるのと作るのは一つの文で、合計 20 まで。超えたら 409 `family_limit`。審査の後に消す家族もこの印で引く
- 戻り道は注意の一行だけ（「家族のこと」で自分のリンクを作って控える）。cookie は一つなので、ほかの人を開くと新しい家族に戻れなくなる。端末に合言葉を持つ経路は増やさない

### 守りを絞る
- 「決めたこと」の守りを次に置き換える: 案内の鍵（DEMO_GUIDE_KEY）が設定されている間、`is_demo` で印のない家族の人とリンクは変えられない。案内から作った家族は変えられる。止まるのはその環境の印のないデモの家族すべて（デモの家族を新しく作る運営の手順も、2 人目で 403 のまま）
- 「鍵とリンクの両方が読める間」をやめた。鍵やリンクの設定が壊れてページが閉じていても、鍵があれば守りは残る（閉じる側に倒す）。鍵を消せばページも守りも閉じる。判定は読み取りを足さない
- 退けた案: 列を足す移行（正しい形だが提出前日に D1 の移行が要る）。4 人のリンクの合言葉を引いて家族 ID と比べる（リンクが全部無効だと 4 人の家族を見分けられず開いてしまう。毎回読み取りが増える）。デモの家族の総数を数える（ほかのデモの家族を数える）

### 帯は一押しで翌朝へ
- 「次の時間帯へ」（朝 → 昼 → 夜 → 翌朝で 3 回）を「次の日へ」に替え、どの時間帯からでも一押しで翌朝へ進め、毎朝の処理（同じ runMorning）を呼ぶ。「進めています」は押している間いつも出す。朝昼夜の値はデータに残す
- 毎朝の処理を翌朝の日付で先に走らせ、終わってから時計を動かす（runMorning の選択肢 forDate。渡すのは時計のボタンだけ）。前は時計を先に動かしていて、待ちの間に誰かが開くと新しい日の固定の入り口ができ、その人だけ Claude の問いかけにならなかった（qa-engineer が見つけた）。待ちの間は前の日の画面のまま。途中で処理ごと止まった（接続が切れて打ち切られた）ときは、時計は動かず、押し直せば足りない分だけ作る。毎朝の処理が例外で失敗したときは、受け止めて時計を進め、開いた人は固定の入り口になる（押し直しで Claude を呼び直し続けるより、翌日へ進むほうがデモが詰まらない）
- 画面の日付（from）を送り、時計が from のときだけ一つの UPDATE で動かす。別のタブや別の審査員が同時に押しても一日しか進まない。毎朝の処理は重なることがあるが、一人一日に入り口は一つで、Claude の呼び出しが増えるだけ。行で止める形（印の列を足す）は移行が要るので採らない。from が今の日付と違えば何もせず今の時計を返す。from がなければ今の時計を from とみなす
- Claude の問いかけが検査で落ちた人は、今までどおりその日は固定の問いかけになる（案内の「Claude の問いかけになります」が外れることがある）
- 上の「帯の待ち」の「夜 → 翌朝だけ出す」「押したときの時間帯で決める」は、これで要らなくなった

## 追記（2026-11-07）: 鍵を 32 文字にする（人間の決定）
- 提出フォームの欄は URL と説明を合わせて 150 文字まで。`-hex 32`（64 文字）では説明が入らないので、`openssl rand -hex 16`（32 文字、128 ビット）に替えた。コードの下限（32 文字）のままで、コードは変えない
- 短縮 URL は使わない（鍵を外部に預けることになり、そのサービスが止まると開けない）
