# 0002 実行環境を Cloudflare Workers にし、VPS への逃げ道を残す

- 日付: 2026-11-02
- 状態: 採用
- 決めた人: 人間（キックオフ時）

## 決めたこと

- 実行環境は Cloudflare Workers にする。データベースは D1、写真と録音は R2、毎朝の処理は Cron Triggers を使う
- GitHub とつないで自動でデプロイする。develop はプレビュー、main は本番
- 逃げ道を残す。データベースと写真の保存は差し替えられる作りにし、さくらの VPS（Node.js、better-sqlite3、Let's Encrypt）へすぐ切り替えられるようにする
- 初日の終わりまでに Workers で一巡（写真の登録 → 入り口 → 語り → 記録）が動かなければ、VPS に切り替える

## 理由

- 実行環境、データベース、保存、定期処理、自動デプロイが、一つのサービスの中でそろう
- 1週間のハッカソンでは、サーバーの運用（証明書、プロセスの管理、バックアップ）に時間を取られたくない
- （Workers を選んだほかの理由があれば、人間が補記する）

## 退けた案とその理由

- 最初から VPS にする: 運用の手間が増える。ただし、慣れた構成であるため逃げ道として残す
- 逃げ道を用意しない: Workers は初めて使う。つまずいたときに作り直すと、1週間では間に合わない

## 根拠にしたもの

- Workers の制約。sharp などネイティブのモジュールが動かない、処理時間とメモリに上限がある

## 見直す条件

- 初日の終わりの時点で一巡が動かない
- Workers の制約（処理時間、メモリ、使えないライブラリ）のために、要件を満たせないことが分かった
