# 0027 実際の家族（作り手の親）に本番で試してもらう前の線引き

- 日付: 2026-11-03
- 状態: 採用（同意の言葉、消す約束、費用の上限は人間の決定待ち）
- 決めた人: 人間（読み上げを入れること、運営が同意を得て記録を見ること、朝の時刻、端末）。進め方は fable-advisor に相談（メインの会話）

## 決めたこと
- **読み上げを入れて始める。** 0019 の「採るときの形」で作る。毎朝の処理で、問いかけの検査を通った後に音声を作って R2 に保存する。祖父母の画面では自動で流さず、押して聞く。そばに常に「AI の声で読みます」と出す。声と速さは、実機で聞き比べるまでの仮の値にする（/check の初期値）
- **運営は、親の同意を得て本番の記録を見る。** 記録の画面（0025、0026）を本番でも開けるようにする。ただし、0025 が本番で閉じた理由（家族を作る鍵が漏れたときの被害を広げない）は残るので、本番では家族を作る鍵とは別の鍵で守る。守り方は実装の前に fable-advisor に相談し、別の記録に残す。親への同意の言葉に「作り手が記録を見ることがある」を含める
- **毎朝の処理を日本時間 3:00 にする**（Cron `0 18 * * *`、UTC）。6:00 より前に開くと固定の入り口になる（0009）のを避ける
- **親は一人一台で使う。** 祖父母のスマホ（390px 幅）とタブレットの両方で、高齢の人の画面の最低ラインを満たす。家族の画面も、祖父母が開いても読める大きさにする
- 試しの前に、祖父母と家族の画面を直す: 主な動作は横いっぱい、補助のボタンも文字は 20px 以上、送れなかった後に「やめる」、祖父母の画面のエラーの文はひらがなで「できること」を言う、文字で送ったら入力欄を閉じる、音声の長さを出す、添える家族の言葉が声なら本人の録音を聞ける（0015 で決めて未実装だったもの）
- 消す手順（家族 ID から D1 の行と R2 の `families/<id>/` を消す）を書いてから、親に渡す
- 段取り: 家族の場はデモではない家族として作り、家族が写真を入れた翌朝以降に親に渡す（初日は全員が固定の入り口になるため）

## 同意の取り方（2026-11-03 に人間が決定）
- 作り手が、試しの趣旨を伝える電話の中で、口頭で伝えて同意をもらう。伝えること: 写真・声・話した言葉と家族の呼ばれ方を、Anthropic と OpenAI のサーバーに送って処理すること。作り手が記録（Claude が選んだ理由と推測を含む）を見ることがあること。問いかけは AI の声で読むことがあること。消してほしいときは言えば消すこと

## 消す約束（2026-11-03 に人間が決定）

- 消す範囲は家族の場ごと全部（家族 ID を指定して、D1 の行と R2 のファイルをまるごと消す）
- 消すとき: 作り手が決めた任意のとき、本人から消してと言われたとき（1 週間以内）、ハッカソン（Built with Claude: Japan 2026）の期間の試しが終わったとき（試しは 2026-11-10 まで。2026-11-11 に消す）

## 費用（2026-11-03 に人間が判断）
- Anthropic は、ハッカソンで付与された 500 ドルの API クレジットの範囲で足りる（見積もりは多めに見て一日 1 ドル前後、11/10 までで数十ドル）。不具合で呼び出しが続いたときの安全網として、コンソールの月の上限をクレジットの内側に設定しておく
- OpenAI（文字起こしと読み上げ）はクレジットの外。前払いの 10 ドルを手動で入れ、自動チャージは切った（2026-11-03）。残高がそのまま上限になる。残高が尽きると文字起こしと読み上げが静かに失敗する（録音と入り口は残る）ので、試しの途中で残高を見る

## 理由
- 人間の判断（2026-11-03）
- requirements「プライバシー」「家族が語ったことと推測を分ける」、implementation-policy「高齢の人の画面の最低ライン」、0009、0015、0019、0025

## 退けた案とその理由
- 読み上げなしで始める（fable-advisor の推し）: 人間が、祖父母に声でも届けることを選んだ
- 運営は本番の記録を見ない（0025 のまま）: 人間が、同意を得て見ることを選んだ。見られないと、試しで何が起きたかを確かめられない
- 本番の記録の画面も家族を作る鍵で守る: 一つの鍵が漏れたときに、家族を作ることと、実際の家族の語りを読むことの両方ができてしまう
