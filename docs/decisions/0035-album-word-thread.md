# 0035 アルバムの「言葉の糸」（入り口への答えに、元の言葉を添える）

- 日付: 2026-11-03
- 状態: 採用
- 決めた人: 人間（言葉の糸を足すこと。2026-11-03 承認）。形の細部は fable-advisor に相談（取りまとめのエージェント経由。実装は frontend-developer）

## 決めたこと
- 対象: 入り口への答えの語り（narrations.entrance_id が付いたもの）のうち、その入り口の添える家族の言葉（entrances.quote_narration_id と quote_start / quote_end）が引けたものだけ。入り口の種類（claude / fixed）は見ない・出さない
- サーバーで組む: /api/feed の各語りに `quotedFrom`（元の語りの ID、語り手の member ID、引用の文字）を付ける。引用の文字は entranceView と同じ quoteText の経路で作る（「……」の置き換えも同じ）。次のときは付けない: 引用の元がない、quoteText が null か空、入り口の行が引けない、入り口の写真と答えの写真が違う（POST /narrations はこの組を確かめていないので、ここで守る）。入り口の理由・種類・モデル・Claude に渡した語りの ID は feed に載せない
- 引用が 80 字（ENTRANCE_QUOTE_MAX_CHARS）を超えるときは、サーバーが text を null にし、画面は呼ばれ方だけを出す
- 出す文: 「{呼ばれ方}の『{引用そのまま}』から」。長すぎるときは「{呼ばれ方}の言葉から」。引用は切らない（行数で切る・「…」を足すことをしない）。「から」の後に動詞を足さない。日付や「入り口」などの仕組みの語、AI・Claude の語を出さない（words.ts の `home.thread`）
- 出す場所: アルバムのタブだけ。答えの語りの本文の下、ボタンの行の上（本文がない pending / failed の声でも、話者名 → 糸 → ボタン）。補助の文字の体（16px 以上）で、本文（明朝）と見分ける。行全体が一つのボタンで、語りの幅いっぱい、高さは押せる場所の最低以上。押せることは上向きの印と下線でも示す（色だけにしない）
- 押すと、元の語りの位置へ縦に移り、そこにフォーカスを置く（移ってきたときだけフォーカスを受け、離れたら外す）。ID で探して移る。元の語りは今は必ず同じ写真にある（0023）ので帯は動かないが、別の写真にあれば帯もその写真へ動かす。こちらから動かす語りの欄は連動の門（SyncGate）に知らせ、移る動きで帯を切り替えない。引用の範囲は強調しない
- 今日のタブには出さない。逆向き（元の語りの下に「答えた人」）は出さない
- 自分の語りが引用されていても隠さない
- 画面に AI とは書かない。つないでいるのが Claude であることは、デモの語りで伝える前提にする

## 理由
- requirements「AI は黙って語りを記録し、翌日の入り口に活かす」「語りが積み重なると深さを持ったアルバムになる」: 誰のどの言葉が次の語りを呼んだかが、家族自身の言葉だけで見える
- requirements「家族が実際に語った言葉を中心にする。Claude 自身の言葉は最小限」「推測を事実のように見せない」: 出すのは引用そのものと呼ばれ方だけ。入り口を作った理由（Claude の推測）や仕組みの語は出さない
- 引用を切ると、家族の言葉を別の言葉に変えることになる。長いときは引用そのものを出さず、呼ばれ方だけにする
- 写真が違う組は、データの食い違い（または POST の確かめ漏れ）なので、作り話の見え方になる前に止める

## 退けた案とその理由
- 入り口を日ごとのカードで出す: 仕組み（入り口）が前に出て、家族の語りが脇になる
- 「AI が結びました」などの印: AI を前に出す（implementation-policy「家族に見せる言葉」）
- 日付や「入り口」などの仕組みの語を添える: 家族の言葉でない語が増える
- 「〜を見て」「〜に続けて」など、「から」の後に動詞を足す: 答えた人の気持ちや経緯を、アプリが言い当てる形になる
- 引用を切る（行数で切る、「…」を足す）・一文だけ切り出す: 家族の言葉を変える
- 逆向き（元の語りの下に答えた人を出す）: 今回は見送る。写真をまたぐ引用ができたときに一緒に考える（見直す条件）
- 今日のタブにも出す: 今日の入り口のすぐ下に同じ言葉が二度出る
- 固定の入り口では出さない: 種類で出し分けると、入り口の種類が家族に見える形になる。添えた言葉は家族の言葉で、出所は同じ
- 元の語りの引用の範囲を強調する: 移った先はフォーカスで分かれば足りる。範囲を色で示すと、どこが選ばれたか（選んだ仕組み）が前に出る

## 根拠にしたもの
- fable-advisor との相談（2026-11-03、取りまとめのエージェント経由）と人間の承認
- docs/requirements.md、docs/implementation-policy.md「家族に見せる言葉」「高齢の人の画面の最低ライン」、0017、0018、0023、0034

## 見直す条件
- 0023 の見直しで写真をまたぐ引用ができたとき → 帯の横の移動（実装は用意済み）と、逆向きの糸を考える（人間が「親の試しの様子を見てから」と決めた）
- 引用なしの「{呼ばれ方}の言葉から」ばかりになったとき → 固定の入り口の引用に上限を付ける
- 家族が「なぜこの言葉か」を知りたがったとき → 出すかどうかは人間が決める
