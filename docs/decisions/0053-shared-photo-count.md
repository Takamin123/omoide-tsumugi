# 0053 共有した写真の数と一覧を見せる

- 日付: 2026-11-04
- 状態: 採用
- 決めた人: 人間（2026-11-04）。0 枚の人に出さないことと、細部は frontend-developer（人間の推奨に沿う）

## 決めたこと

- 写真を家族に共有する画面（/photos。家族の画面の人だけ。0036）の下に、見出し「共有した写真 12枚」と、自分が共有した写真の小さい一覧を出す
  - 一覧は新しい順（登録した順の新しいほうから）。GET /api/photos?ownerMemberId=（登録の古い順で返る）をクライアントで逆にする
  - 小さい写真はアルバムの小さい写真と同じ 48px 角で折り返す（幅 360px で横にはみ出さない）。押すと拡大の画面（0040 の仕組みのまま）。img は loading="lazy"
  - 選んで送り終えたら（途中で失敗しても）一覧と数を読み直す。読めなかったら前のまま（文を出さない）
  - 0 枚のときは見出しも一覧も出さない（文を足さない）
- 家族のこと（/family）の各人のカードに「共有した写真 n枚」を補助の文字で一行。0 枚の人には出さない
  - サーバー: GET /api/family の members の要素に photoCount（その人の photos の行の数）を足す（FamilyMember）。家族で絞った一つの集計（owner_member_id ごとの count）。祖父母の画面の人にも同じ形で返す（数だけで写真そのものではない）。me には付けない
  - 家族のことを開いたときに家族の様子を静かに読み直す（写真を共有した後に来ても数が古くならない。失敗しても今の画面のまま）
- 言葉は「共有した写真 n枚」（上のメニュー「写真を家族に共有する」と同じ語）。！なし

## 理由

- 10 枚以上入れて、本当に入ったか不安になった（人間）。入れた写真は毎朝 1 枚ずつ「今日」に届くので、入れた直後にはアルバムに見えない。自分の目で数と写真を確かめられる所を作る
- 0 枚の人に「共有した写真 0枚」を出すと、まだ入れていない人（とくに写真を入れない祖父母）への催促に見える（requirements「試す・急かす言葉を出さない」）

## 退けた案とその理由

- 0 枚の人にも「共有した写真 0枚」を出す: 催促に見える
- 家族のことの数を、開いたときに写真の一覧から数える: 家族全員の写真を読むことになる。数だけなら集計一つで足りる
- 写真を共有する画面の一覧を、送る途中で一枚ずつ足す: 送る途中の進み具合の表示と二重になる。送り終えたらサーバーの値にそろえる
