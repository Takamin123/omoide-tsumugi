# 0024 入り口づくりのプロンプト v2（問いかけは引用を繰り返さない）

- 日付: 2026-11-03
- 状態: 採用
- 決めた人: fable-advisor に相談（backend-developer）

## 決めたこと

`src/server/prompts/entrance/v2.md` を今日の版にする（`entrance/v1` は出し比べだけで使い、家族の流れでは使っていない）。v1 からの変更:

- 問いかけで、引用の中身を繰り返したり、標準語に言い換えたりしない。引用から拾ってよいのは、物や場所を指す一語か二語まで。問いかけは、その言葉の先を聞く
- 受け取る人を、呼ばれ方や「あなた」で呼ばない。主語を省く
- 語り手の呼ばれ方は、どの話を指しているか分からなくなるときだけ使う。「〜が話していた」を毎回の型にしない
- 受け取る人がその場にいなかったと分かる写真では、その日の受け取る人自身の思い出は聞かず、語り手の話の中でもっと聞いてみたいところを聞く。写真や語りから離れた一般の問いにしない。「〜に聞いてみましょう」のように仕切る言い方をしない
- 例文は形の違うものを三つ置き、「この形をそのまま使わない」と添える。例文の語は出し比べの架空の家族と重ねない
- reason は 150 字を目安にする（検査は 200 字のまま。間は数え間違いの余白）

### 次の版（v3）でやること（今日は入れない）
- 問いかけを書く前に、受け取る人がその場にいたか（いた／いなかった／分からない）を決めさせる。推測でよく、reason か出力の項目に残し、問いかけには出さない。fable-advisor はスキーマの項目にすることを推す
- いなかった場合の例を置く（例: 「おじいちゃんのこの話で、もっと聞いてみたいのはどんなところですか」）。このときは語り手の呼ばれ方を使ってよい
- 問いかけに拾う語は、画面に出る引用（quote の text）の中から選ぶ

## 理由

- 画面では、引用は語り手の呼ばれ方と一緒に出る。問いかけで繰り返すと、同じ中身が二度、二度目は Claude の標準語訳で見える。requirements「Claude 自身の言葉は最小限」「家族の言葉を中心に」に反する
- 受け取る人を呼ばれ方で呼ぶと、アプリが家族の一員のような口ぶりになる
- 写真から離れた一般の問いは、答えた語りがその写真に付くので、アルバムが濁る
- 今日のゴールは「本物で一巡が回る動く版」。v2 は方針違反がなく、残る課題（その場にいなかった人への問い）は家族に害を与える形ではないので、v3 は一巡が回ってからにする

## 退けた案とその理由

- v1 のまま採用: 引用の繰り返しと標準語への言い換えが多い
- 受け取る人の呼ばれ方を、機械の検査の禁止語に足す: ばあばに「お母さん（ばあばの母）」の話を問うときなどに誤検出が出る。v2 で呼びかけは 0/10 だった
- 今日 v3 まで作る: 一巡が回る前に時間を使う
