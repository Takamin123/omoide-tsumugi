# 0059 画面の見直し（文字・紙の色・大きさの分け方・見た目）

- 日付: 2026-11-05
- 状態: 採用
- 決めた人: 人間（2026-11-05。下の「人間が決めたこと」。Claude Design のキャンバスの改善案を見て「うん、実装に入って」）。定数の分け方と細部は frontend-developer。モックにあった言葉・飾りを入れるかは人間と fable-advisor（0061）

## 決めたこと

### 人間が決めたこと
人間の言葉: 今の画面は「分かりやすいけど、どんくさい」。

1. 文字: 家族の言葉（引用、語り、返事、入力欄）も明朝をやめて UD ゴシック（`--font-gothic`）。行間 1.6、字間を詰める（`font-feature-settings: "palt"`）。読みやすさを優先する
2. 家族の言葉（語り・添える家族の言葉）の箱だけ、淡い紙の色の地 `#f6f3ee`・文字 `#2a2420`。問いかけ・ボタン・日付・画面全体の地（`--home-bg`、クリーム色にしない）には付けない。「返事」のタブの新しい返事の強調は淡い青のままで、紙の色と分ける
3. 祖父母の画面は漢字を使ってよい（[0060](0060-elder-words-kanji.md)）
4. 家族の画面（高齢者でない人の画面）は高齢者を考慮しない。ふつうに使いやすいスマホの大きさでよい（目安: 本文 16〜17px、問いかけ 19px、答えるボタン 48px、聞く・返事 36〜40px、補助 13px、タブ 52px＋文字 12px と印）。implementation-policy の「高齢の人の画面の最低ライン」は祖父母の画面だけに当てる。styles.css の定数を家族用と祖父母用に分ける。祖父母の画面の大きさは下げない（キャンバスでは今以上）
5. 見た目: 灰色の太い枠の箱をやめて白いカード＋柔らかい影。主役のボタン（声で話す／話す）は青で塗り、もう一方（文字で書く／書く）は青い枠。「聞く」「読み上げ」は丸い再生印の付いた淡い青の丸いボタン。問いかけと答えるボタンを一枚のカードに。問いかけは `text-wrap: balance`、本文は `pretty`。押せるものは押した瞬間に少し沈む（scale 0.97・0.1 秒、transform だけ、prefers-reduced-motion では付けない）。下のタブは印＋語、今いるタブは太字と淡い青の地
6. アルバム: 写真の白い縁に影、わずかな傾き、前後の写真を両端に薄くのぞかせる、矢印は丸いボタン、何枚目かの下に点。語りは一枚のカードにまとめ、返事は一段下げる。「この写真に追加する」は点線の枠

人間が決めていないので、モックと食い違っても今の振る舞いを残すもの: 0008 の答えるボタンのすぐ上の話者の呼ばれ方（祖父母）、送った後の流れ（モックは送った声の文字起こしを出し、話す・書くを省いていた）、0034・0043・0045 の高さの約束（祖父母の画面）、画面の流れ・データ・サーバー。

### 定数の分け方（frontend-developer）
- `styles.css` の `:root` は家族の画面の大きさ（本文 16px、家族の言葉 17px、問いかけ 19px、補助 13px、補助のボタン 15px・40px、答えるボタン 48px、押せる場所 44px、間 8px、タブ 52px・語 12px）
- 祖父母の画面（`.home-shell.elder`。body に置く写真の拡大の画面も `.viewer.elder`）は、`.elder` の中で同じ名前の定数を祖父母の値に替える。値はこれまでの最低ラインの値のまま（本文 22px、補助 17px、補助のボタン 20px・52px、主な動作 72px、間 12px、タブ 64px 以上・語 20px）。部品は共有し、大きさだけが違う（0043 の形のまま）
- 祖父母のタブレットの問いかけは 32px → 34px（モックに合わせて上げた）
- 家族の言葉の行間は両画面とも 1.8 → 1.6（人間の決定 1。最低ラインの 1.5 以上）
- 祖父母の画面の家族の言葉の箱は、横の余白を詰める（0.5rem。幅 360px・文字 150% で声の語りの [聞く][返事] を一行に保つ。0045）
- 問いかけは `text-wrap: balance` に `word-break: auto-phrase` を添える（balance だけでは「ほ／かに」のように語の途中で折れた）
- リンクを開いた直後の「開いています」、読み込み中、リンクのエラーの文は、人がまだ決まっていないので祖父母の画面の大きさで出す（[0060](0060-elder-words-kanji.md)）
- 写真の拡大の画面の「閉じる」は、家族の画面ではふつうの主な動作の大きさ、祖父母の画面では祖父母の主な動作の大きさ（0040 の「家族の画面でも祖父母の大きさ」は、決定 4 で祖父母の画面だけにした）

### 置き換えるもの
- `--font-told` の明朝（0028「家族の言葉は明朝」）→ ゴシック。`--font-mincho` は消した
- 0043「大きさ」の、家族の画面と祖父母の画面の大きさの関係（家族の画面も最低ラインを満たし、祖父母はその上に大きくする）→ 家族の画面はふつうのスマホの大きさ、最低ラインは祖父母の画面だけ
- implementation-policy「高齢の人の画面の最低ライン」の範囲 → 祖父母の画面だけ。家族の画面には「家族の画面の大きさ」の節を足した
- 0040 の「閉じる」の大きさ（上のとおり）

## 理由
- 人間の決定。明朝は細く、小さい画面で読みにくい。紙の色の箱は、家族が語った言葉と、Claude の推測（問いかけ）・アプリの言葉を見た目で分ける（requirements「家族が語ったことと Claude の推測をはっきり分ける」）
- 家族の画面に最低ラインを当てると、ふつうのスマホの人には大きすぎ、一画面に入る量が減って「どんくさい」。祖父母の画面は親の端末（らくらくスマホ、タブレット）のために今の大きさを保つ
- 同じ名前の定数を `.elder` で替える形なら、部品の CSS は一つのまま（0043「二重に持たない」）

## 退けた案とその理由
- 家族の画面の定数と祖父母の画面の定数を別の名前で持ち、部品の CSS を二通り書く: 0043 の「部品を共有し、大きさだけ違う」が崩れ、直しが片方に届かない
- 明朝を太くして字間を詰める（キャンバスの B 案）: 人間が C（ゴシック）と D（言葉の箱だけ色）を選んだ
