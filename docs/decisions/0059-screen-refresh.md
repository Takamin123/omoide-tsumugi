6. アルバム: 写真の白い縁に影、わずかな傾き、前後の写真を両端に薄くのぞかせる、矢印は丸いボタン、何枚目かの下に点。語りは一枚のカードにまとめ、返事は一段下げる。「この写真に追加する」は点線の枠

人間が決めていないので、モックと食い違っても今の振る舞いを残すもの: 0008 の答えるボタンのすぐ上の話者の呼ばれ方（祖父母）、送った後の流れ（モックは送った声の文字起こしを出し、話す・書くを省いていた）、0034・0043・0045 の高さの約束（祖父母の画面）、画面の流れ・データ・サーバー。

### 今日・返事の画面（frontend-developer。2 つ目のコミットの後）
- 白いカード `.card-soft`: 入り口の写真と添える言葉、問いかけ（見出し・問いかけ・読み上げ・「送りました」・答えるボタン）、返事のタブの写真ごとの節
- 家族の画面は、答えるボタンを問いかけのカードの中に置き、スクロールする欄の外の段（0034 の「声で」「文字で」の段）に留めない（`answerPlace` の `docked`）。理由: 決定 5「問いかけと答えるボタンを一枚のカードに」。段は、最低ラインの大きさで 360px・150% のときに問いかけが欄の下の方に押し出され、ボタンが見えなくなるのを防ぐためのものだった（0034）。家族の画面の大きさを下げた（決定 4）ので、ふつうのスマホでは写真・添える言葉・問いかけ・ボタンが一画面に入りやすくなり、入らないときも問いかけのすぐ下にボタンがある
- 祖父母の画面は段のまま（0034・0043 の高さの約束。人間が決めていない）。モックの祖父母の一枚のカードとは違う
- 答えるボタン: 「声で話す」「話す」は青で塗り（`.choice-fill`）、「文字で書く」「書く」は青い枠（`.choice-line`）。家族の画面のボタンにも印（マイク・ペン）を付けた。ボタンの並びの幅が 18rem 未満（家族の 360px・文字 130%・150% など）のときは印を出さず、語を言葉の切れ目でだけ折る（印があると「文字／で／書く」と語の途中で折れた）
- 「聞く」「読み上げ」: 淡い青の丸いボタンに、青い丸の白い印（`.listen-dot`）。祖父母の画面の語りの行では、印を文字の 1.2 倍にし左の余白を詰めて、[聞く][返事] の幅を前と同じに保つ（0045）
- 「返事」: 白い丸いボタン。家族の画面だけ返事の印を付ける（祖父母の画面は幅を保つため付けない）
- 押した瞬間に沈む: `button` と `.button` の `:active` で `scale(0.97)`、0.1 秒。`prefers-reduced-motion` では付けない。iOS のために文書に何もしない touchstart を付けた（main.tsx）。青のボタンは押した間に少し濃く、淡い青のボタンは少し濃い淡い青に

- 返事のタブの写真は 4rem（祖父母 6rem）の正方形（0058 の「小さめの写真」をモックに合わせて小さくした）

### アルバム（frontend-developer。3 つ目のコミットの後）
- 写真の白い縁に影と -0.6 度の傾き。影はモックより小さい（帯は横に動かすので縦の外が切れる。帯の下の余白に収まる大きさにし、帯は高くしない）。前後の写真を帯の両端に薄く（透明度 0.45、±2 度）1.25rem だけのぞかせる。のぞく写真は帯の後ろの飾りで、押せず、めくっても動かない（めくる操作と何枚目かの決まりは前のまま。帯の一枚の幅を変えると、何枚目かを測る決まり（lib/album.ts）が崩れるため）
- 矢印は丸いボタン（半透明の台紙の色に淡い縁）。大きさは押せる場所の定数のまま
- 何枚目かの行に点（飾り、aria-hidden）を「4枚のうち 2枚」の左に並べる。13 枚以上のときと、行の欄が 16rem より狭いとき（スマホの文字 150% など）は点を出さない（行を増やさない。祖父母の画面の高さの約束）。モックの祖父母の画面は点を文字の下に置いていたが、一行増えて「語り一つ」が入らなくなるので採らない
- 写真ごとの語りは一枚の白いカード。カードの上の余白（0.5rem）と見出しとの間（0.5rem）を合わせて、前の見出しと語りの間（1rem）と同じにする（「語り一つ」の高さを変えない）。カードの横の余白は 0.5rem。祖父母の画面で語りの欄が 20rem より狭いとき（スマホの文字 150% など）は横の余白をなくす（0.5rem あると 360px・150% で声の語りの話者名の行が二行に折れ、「語り一つ」が 31px 足りなくなった）
- 返事は一段下げる（家族 1.25rem、祖父母 0.75rem）
- 「この写真に追加する」は点線の枠で横いっぱい、＋の印。カードの下に置き、前の区切りの線はやめた。送っている間は枠を淡くし、地を淡い灰色にする（前は点線で示していたが、点線はふだんの形になった）
- 節の見出し（小さい写真 48px・撮影日・場所・何枚目か）は 0041 のまま（モックの祖父母の 64px の写真は採らない。高さの約束）

## 理由
- 人間の決定。明朝は細く、小さい画面で読みにくい。紙の色の箱は、家族が語った言葉と、Claude の推測（問いかけ）・アプリの言葉を見た目で分ける（requirements「家族が語ったことと Claude の推測をはっきり分ける」）
- 家族の画面に最低ラインを当てると、ふつうのスマホの人には大きすぎ、一画面に入る量が減って「どんくさい」。祖父母の画面は親の端末（らくらくスマホ、タブレット）のために今の大きさを保つ
- 同じ名前の定数を `.elder` で替える形なら、部品の CSS は一つのまま（0043「二重に持たない」）

## 退けた案とその理由
- 家族の画面の定数と祖父母の画面の定数を別の名前で持ち、部品の CSS を二通り書く: 0043 の「部品を共有し、大きさだけ違う」が崩れ、直しが片方に届かない
- 明朝を太くして字間を詰める（キャンバスの B 案）: 人間が C（ゴシック）と D（言葉の箱だけ色）を選んだ
