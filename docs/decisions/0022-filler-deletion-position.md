# 0022 言いよどみを削ってよい場所（clean_transcript v2）

- 日付: 2026-11-03
- 状態: 採用
- 決めた人: fable-advisor に相談（backend-developer）
- 関連: 0018 の「意味のないフィラーを取る」の解釈を絞る。0018 は変えない

## 決めたこと
- 言いよどみを削ってよいのは、文の頭か句読点の直後にあり、取っても意味が変わらないものだけ
- 文の途中の、言いよどみに見える語は削らない。言いよどみか意味のある語か分からなければ、聞き間違いの印で囲む
- 語の一覧は持たず、位置で決める。プロンプト（`src/server/prompts/clean_transcript/v2.md`）で守り、アプリの検査は足さない
- 出し比べ（`evals/clean-transcript.eval.ts`）に、削られてはいけない方言の語の回帰を置く（n03「親戚がえっと集まって」、n05「お酒をえーと飲んで」）。残ったか、消えたか、印で「……」に隠れたかを数える。プロンプトを触るたびに走らせる（機械的な検査の代わり）

## 理由
- v1 は、広島の言葉の「えっと」（たくさん）を、出し比べの 3 回とも削った。削るだけなので部分列の検査を通り、意味が黙って落ちる。家族に見せるのは実際に語った言葉にする（requirements「記録と言葉」「方言を考慮する」）
- 読みにくさより、言葉の意味が落ちることのほうが重い
- 位置で決める規則は、語の一覧なしに方言をまたいで効く
- v2 では 6 回とも残った（docs/evals/2026-11-03-clean-transcript.md）

## 退けた案とその理由
- 方言の話し手は、言いよどみを一切削らない: 話し手の申告に守りを預けることになる。申告が標準語の人の方言や、混ざった話し方で同じ事故が起きる。プロンプトが話し手で分岐する
- アプリの検査で、特定の語の削除を止める: 語の一覧が方言ごとに抜ける。誤検知で整形全体が null になり、句読点の利益まで失う

## 根拠にしたもの
- 出し比べ: docs/evals/2026-11-03-clean-transcript.md（v2）と 2026-11-03-clean-transcript-v1.md（v1）。架空の家族 family-a、Haiku、7 件 × 3 回。v1 を 1 度、v2 を 2 度
  - n03 の文字起こし「うちに親戚がえっと集まって、こたつに入りきらんで。」→ v1「うちに親戚が集まって、こたつに入りきらんで。」（3 回とも）／ v2「うちに親戚がえっと集まって、こたつに入りきらんで。」（6 回とも）
  - n05 の文字起こし「うちの父がお酒をえーと飲んで、」→ v1「うちの父がお酒を飲んで、」（3 回とも）／ v2「うちの父がお酒をえーと飲んで、」（6 回とも。印なし）
  - n05 の聞き間違い: v1 は「交番」「お仲間さん」に 3 回とも印。v2 は「交番」に 6 回とも、「お仲間さん」に 6 回中 5 回（1 回は印なしで、直されずに残った）
  - fixture は n05 の「えーと」を聞き間違い（intended えっと）として印を期待しているが、v2 は印を付けずに残す。言葉が残るのでよしとし、印は求めない（印が付くと「……」に隠れるため）
