# 0054 入れた本人が、前もって自分の写真に言葉を添える

- 日付: 2026-11-04
- 状態: 採用
- 決めた人: 人間（2026-11-04、親の試しの初日の感想から）。印の見せ方と細部は frontend-developer（人間の指示の範囲で控えめに）

## 決めたこと

- 写真を家族に共有する画面（/photos。家族の画面の人だけ）の「共有した写真 n枚」の一覧（0053）で、写真を押すとその写真を選ぶ
  - 選んだ写真は一覧の中で太い枠（aria-current）。一覧の下に、その写真を大きめに（押すと拡大の画面。0040 の仕組みのまま。小さい写真から直接は開かない）、付いている語り（自分・ほかの家族。聞くだけで、返事はアルバムで）、見出し「言葉を添える」、答えの欄を出す。選んだら欄が見えるところまで送る
  - 答えの欄は今日の答え・返事と同じ部品（声で話す・文字で書く・とりなおす。送れたら「送りました」）。送る先はその写真だけ（entranceId・replyToId とも null）。サーバーは変えない（POST /api/narrations はすでに受ける）
  - 送れたら語りを読み直し（/api/feed）、一覧の印と語りを替える。録り直しなら前の語りを消し終えてから読み直す
- 一覧の印: 家族の誰かの言葉が付いた写真（/api/feed に並ぶ写真）の右下に、白い丸に線の吹き出しの小さな印（色だけに頼らない）。読み上げの名前は「n枚目」／「n枚目（言葉あり）」（新しい順の何枚目か）。言葉のない写真には何も足さない
- 言葉は「言葉を添える」（見出し）だけを足した。！なし。「まだ添えていない写真があります」のような催促の文は出さない
- 添えた語りは普通の語りとして扱う。その写真は語りのある写真としてアルバムに出る（0034 の「語りのある写真がアルバムの一枚」のまま。人間の決定）

## 理由

- 親（祖父母の画面）に毎朝届く一枚は、ほかの家族の言葉が付いた写真を優先する（src/server/core/entrance-claude.ts）。言葉を付けられる場所が「今日」の一枚への答えとアルバムの返事しかなく、入れた本人も一日一枚しか付けられない。言葉の付いた写真を使い切ると、親に言葉なしの写真が出る
- 親の試しの初日、言葉付きの写真が一枚だけで、翌日から言葉なしの写真が出ると分かり残念がった。本人が前もって何枚か添えておけば、言葉なしの写真が親に出ることをほぼなくせる
- 印は、どの写真に添えたかを本人が見失わないため。言葉のない写真の側に印を付けると催促に見えるので、ある側に付ける

## 退けた案とその理由

- 写真を入れるときに一言ずつ書かせる: 枚数が多いと重い。後から添えられない
- 選んだ写真の語りに返事の欄も付ける: 一画面に答える場所が二つになる。返事はアルバムでできる
