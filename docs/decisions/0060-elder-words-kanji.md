# 0060 祖父母の画面の言葉を漢字かなまじりにする

- 日付: 2026-11-05
- 状態: 採用
- 決めた人: 漢字を使ってよいことと、家族の「取り直す」も「録り直す」にそろえることは人間（2026-11-05。[0059](0059-screen-refresh.md) の決定 3）。一つひとつの語とエラーの文は fable-advisor に相談（frontend-developer）

## 決めたこと

- 祖父母の画面のボタンは一語のまま、漢字かなまじりにする（`src/client/words.ts` の `elderWords`）
  - はなす → 話す、おわる → 終わる、おくりました → 送りました、おくる → 送る、やめる → やめる（そのまま）、もういちど → もう一度、かく → 書く、へんじ → 返事、きく → 聞く、とめる → 止める、とりなおす → 録り直す、とじる → 閉じる、よみあげ → 読み上げ
  - 読み上げの名前「ばあばの こえを きく／とめる」→「ばあばの声を聞く／止める」、「マイクを じゅんびしています」→「マイクを準備しています」（どちらも家族と同じ文字列。家族の関数を共有する）
  - 「AI の声で読みます」（0019）はそのまま
- エラーの文も字だけ漢字かなまじりにする。「できること」を言う中身（0028）は変えない
  - 「開けませんでした。「もう一度」を押してください」「開けませんでした。家族に知らせてください」「送れませんでした。「送る」を押すと、もう一度送ります」「マイクが使えません。家族に知らせてください」
- 家族の「取り直す」も「録り直す」にそろえ、両画面で共有の一文を「録り直せませんでした。前の声は残っています」にする
- リンクを開いた直後の「開いています」、読み込み中、リンクなし・読めなかったときの画面は、人がまだ決まっていない（祖父母の画面の人かもしれない）ので、祖父母の画面の大きさ（`.elder`）で出す（0059 で家族の画面の大きさを下げたため、祖父母に 16px で出ていた。qa-engineer の指摘）。その画面のエラーの一文（補助の文字）も祖父母の本文の大きさにする。文は家族向けの errors のまま（人がまだ決まっていない）
- 祖父母の答え方は「話す」「書く」、家族は「声で話す」「文字で書く」のまま（0043 の違い）
- 置き換え: 0008「祖父母のボタンは一語のひらがな」、0028「エラーの文はひらがなで」、0043・0045・0058 の「ひらがな」の記述 → 「一語（漢字かなまじり）」。祖父母の画面と家族の画面で語が同じになったもの（話す・終わる・送る・送りました・返事・聞く・止める・閉じる）は、words.ts で別に持ったまま（画面ごとの言葉の置き場 `words.screen` の形は変えない）

## 理由
- 人間の決定。人間は 0050・0055 で「ひらがなだけだと逆に読みづらい」として、祖父母の画面の文を漢字まじりにしていた。その延長
- 「開けませんでした」は「あけませんでした」と読まれても意味が同じ。家族の「開いています」「開きなおしてください」と同じ字。「ひらけませんでした」を残すと、その一文だけひらがなが残る
- 「録り直す」は人間がモックで選んだ字。祖父母だけ替えると、両画面で共有の一文「取り直せませんでした」とボタンの字が食い違う（0043「同じものには同じ形を一つ」）

## 退けた案とその理由
- 「ひらけませんでした」を残す: 上のとおり
- 家族を「取り直す」のまま: ボタンと共有の一文の字が食い違う
- 祖父母も「声で話す」「文字で書く」: 0008「祖父母のボタンは一語」。人間の決定 5 の書き方「声で話す（話す）」のとおり
